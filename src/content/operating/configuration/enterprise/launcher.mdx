<Tip>Set these values in your runtime `.env` or `enterprise.env` file before starting the enterprise deployment.</Tip>

The enterprise launcher starts and coordinates the services in your production stack. Use these variables to connect the launcher to shared infrastructure and provide the license used at startup.

```dotenv .env wrap
ENTERPRISE_POSTGRES_URL=postgres://user:password@host:5432/postgres?sslmode=require
ENTERPRISE_REDIS_URL=redis://host:6379/0
ENTERPRISE_LICENSE_B64=your_base64_license_string
ENTERPRISE_LICENSE_FILE=/run/secrets/blnk-enterprise.lic

# Core and Cloud use separate databases on the Postgres instance above
ENTERPRISE_CORE_DB_NAME=your_core_database
ENTERPRISE_PLANE_DB_NAME=your_cloud_database
ENTERPRISE_PUBLIC_PORT=8080
ENTERPRISE_PUBLIC_URL=https://ledger.yourdomain.com
```

<ParamField name="ENTERPRISE_POSTGRES_URL" required>
Postgres connection string used by the launcher to derive the Core and Plane database connections. Point this at the Postgres server that hosts both databases.
</ParamField>
<ParamField name="ENTERPRISE_REDIS_URL" required>
Redis connection string passed to Core for queueing, caching, and other Redis-backed runtime work.
</ParamField>
<ParamField name="ENTERPRISE_LICENSE_B64">
Base64-encoded license string from your onboarding email. Takes precedence over `ENTERPRISE_LICENSE_FILE` when both are set.
</ParamField>
<ParamField name="ENTERPRISE_LICENSE_FILE">
Path to your `.lic` license file mounted into the container. Use this instead of `ENTERPRISE_LICENSE_B64` when you mount the license as a file.
</ParamField>
<ParamField name="ENTERPRISE_CORE_DB_NAME" required>
Name of the Postgres database for Blnk Core ledger data.
</ParamField>
<ParamField name="ENTERPRISE_PLANE_DB_NAME" required>
Name of the Postgres database for Plane, which powers the Cloud Dashboard.
</ParamField>
<ParamField name="ENTERPRISE_PUBLIC_PORT" default="8080">
Port the launcher exposes for the public Plane gateway. Map your host or load balancer to this port when running the deployment.
</ParamField>
<ParamField name="ENTERPRISE_PUBLIC_URL" required>
Public URL where users open the Cloud Dashboard, including the scheme such as `https://`. Use the same origin in `CORS_ORIGINS`.
</ParamField>
