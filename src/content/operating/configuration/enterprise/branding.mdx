Customize the Cloud Dashboard theme to match your brand colours. Set your organization name and primary colour so the dashboard feels like your product, not a generic install.

```dotenv .env wrap
ENTERPRISE_BRAND_NAME=Acme Ledger
ENTERPRISE_BRAND_PRIMARY_COLOR="#A34EF4"
ENTERPRISE_BRAND_LOGO_URL=https://cdn.acme.com/logo.svg
ENTERPRISE_BRAND_FAVICON_URL=https://cdn.acme.com/favicon.ico
ENTERPRISE_BRAND_OG_IMAGE_URL=https://cdn.acme.com/og-image.png
ENTERPRISE_BRAND_HELPER_LINKS_JSON={"ledgers":"https://docs.acme.com/ledgers","balances":"https://docs.acme.com/balances"}
```

<ParamField name="ENTERPRISE_BRAND_NAME">
Display name used for your deployment in the Cloud Dashboard.
</ParamField>
<ParamField name="ENTERPRISE_BRAND_PRIMARY_COLOR">
Primary accent color used by the Cloud Dashboard UI. Use a six-digit hex color value, such as `"#A34EF4"`.
</ParamField>
<ParamField name="ENTERPRISE_BRAND_LOGO_URL">
URL for the logo shown in the Cloud Dashboard.
</ParamField>
<ParamField name="ENTERPRISE_BRAND_FAVICON_URL">
URL for the browser favicon.
</ParamField>
<ParamField name="ENTERPRISE_BRAND_OG_IMAGE_URL">
URL for the Open Graph preview image.
</ParamField>
<ParamField name="ENTERPRISE_BRAND_HELPER_LINKS_JSON">
JSON object that overrides learn-more banner and CTA links in Cloud. Supported keys: `ledgers`, `ledgerDetails`, `balances`, `transactions`, `identities`, `reconciliation`, `alerts`.
</ParamField>
