Configure object-storage archiving for your Lake service.

When enabled, Lake copies eligible older transactions, balances, ledgers, and identities into verified Parquet files while hot Postgres stays lean. 

Lake keeps archive indexes in sync and leaves hot database rows untouched unless purge is explicitly enabled.

```dotenv .env wrap
LAKE_ENABLED=true
LAKE_ARCHIVER_ENABLED=true
LAKE_S3_BUCKET=your-bucket
LAKE_S3_ENDPOINT=https://your-s3-endpoint
LAKE_S3_ACCESS_KEY_ID=
LAKE_S3_SECRET_ACCESS_KEY=
LAKE_S3_REGION=auto
LAKE_S3_PATH_STYLE=true
```

<ParamField name="LAKE_ENABLED" default="false">
Turns on the lake feature in Plane.
</ParamField>
<ParamField name="LAKE_ARCHIVER_ENABLED" default="false">
Starts the background worker that archives eligible old rows.
</ParamField>
<ParamField name="LAKE_S3_BUCKET">
Object storage bucket where Parquet archive files and index files are stored.
</ParamField>
<ParamField name="LAKE_S3_ENDPOINT">
S3-compatible endpoint (e.g., DigitalOcean Spaces, R2, MinIO, or AWS S3 endpoint).
</ParamField>
<ParamField name="LAKE_S3_ACCESS_KEY_ID">
Access key used by Plane to write/read archive objects.
</ParamField>
<ParamField name="LAKE_S3_SECRET_ACCESS_KEY">
Secret key used with the access key. Store this as a secret.
</ParamField>
<ParamField name="LAKE_S3_REGION" default="auto">
Region passed to the S3 client. `auto` is useful for S3-compatible providers.
</ParamField>
<ParamField name="LAKE_S3_PATH_STYLE" default="true">
When set to `true`, uses path-style object URLs (`endpoint/bucket/object-key`) instead of virtual-host style (`bucket.endpoint/object-key`).
</ParamField>
