This section documents the Blnk Watch REST API. Use these endpoints to send transactions for real-time risk evaluation, manage compiled instructions, and sync rules from Git. Each page lists the HTTP method, path, parameters, example requests, and response fields for one operation.

### Base URL

By default, Watch listens on `http://localhost:8081`. Set the host and port in your [Watch configuration](/watch/configuration) when deploying to production.

<Note>
If you're using the Watch service included with your Production License, set the base URL to `https://ENTERPRISE_PUBLIC_URL/watch`. Otherwise, use the publicly accessible base URL for your Watch deployment.
</Note>

## Endpoint groups

Transactions covers injecting a transaction and reading its verdict. Instructions covers compiling and storing Watch DSL scripts. Git sync covers repository status and a manual script pull.
