Open developer docs from the terminal, or print Docs MCP install steps for your coding agent.

| Command | Description |
| :-- | :-- |
| (default) | Open the docs install page in your browser |
| `mcp` | Print how to add the Blnk Docs MCP to your agent |

## Open the docs

Jump from the terminal to guides and API reference when `help` is not enough.

```bash blnk docs
blnk docs
```

## `mcp`

Prints the server name, URL, and JSON you paste into your agent's MCP config. Use it when you are setting up Cursor, Claude Code, or another client and want the install steps in the terminal.

```bash blnk docs mcp
blnk docs mcp [options]
```

<SectionLabel icon="settings-2">Options</SectionLabel>

| Option | Type | Description |
| :-- | :-- | :-- |
| `--json` | boolean | Print only the MCP config object as JSON |
| `-h, --help` | boolean | Show help for this command |

<SectionLabel icon="list-ordered">Usage</SectionLabel>

<Steps>
<Step title="Print install steps">
```bash Print Docs MCP install steps
blnk docs mcp
```

```text 200 Success icon="check-circle"
Docs MCP
Add this server to your agent's MCP config. The name is blnk-docs. The URL is https://docs.blnkfinance.com/mcp.
```

For JSON only:

```bash Docs MCP as JSON
blnk docs mcp --json
```

```text JSON icon="check-circle"
{
  "mcpServers": {
    "blnk-docs": {
      "url": "https://docs.blnkfinance.com/mcp"
    }
  }
}
```

After you add the server, reload MCP or start a new chat if the tools do not appear yet. See [Docs MCP](/docs-mcp) for how the tools work.
</Step>
</Steps>
