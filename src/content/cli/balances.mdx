Use the `balances` command to list, create, and update balances on your connected Core instance.

| Command | Alias | Description |
| :-- | :-- | :-- |
| list | l | Browse balances in a table; add `--id` for one record |
| create | c | Open a balance on a ledger with flags, or prompts when no field flags are passed |
| update | u | Link an existing balance to an identity |
| at | | Get a balance as it stood at a timestamp |
| lineage | | Get the provider breakdown when fund lineage is enabled |
| snapshots | | Start daily snapshots of your balances |

## `list`

Browse balances across your ledgers in a paginated table with amounts, credit/debit totals, and inflight columns. Use `--{field}` filters (for example `--currency`) to narrow results before you fetch one record with `list --id`.

```bash blnk balances list
blnk balances list [options]
```

<SectionLabel icon="settings-2">Options</SectionLabel>

| Option | Type | Default | Description |
| :-- | :-- | :-- | :-- |
| `--{field}` | string | - | Filter by any indexed field (for example `--currency "USD,EUR"`). |
| `-p, --page` | integer | `1` | Page number. |
| `--per-page` | integer | `10` | Results per page. |
| `--json` | boolean | - | Print the Core response as JSON instead of the table. |
| `-h, --help` | boolean | - | Show help for this command. |

## `list --id`

Look up one balance by `balance_id` and print a readable summary of ledger link, identity, and balance breakdowns. Pass `--json` when you need the full API object for scripts or support tickets.

```bash blnk balances list --id
blnk balances list --id <balance-id> [options]
```

<SectionLabel icon="settings-2">Options</SectionLabel>

| Option | Type | Required | Description |
| :-- | :-- | :-- | :-- |
| `--id` | string | Yes | Balance ID to fetch (for example `bln_01dab2b7-3ec7-4253-b302-edd947423883`). |
| `--json` | boolean | No | Print the full API object as JSON instead of a formatted summary. |
| `-h, --help` | boolean | No | Show help for this command. |

<SectionLabel icon="list-ordered">Usage</SectionLabel>

<Steps>

## `create`

Open a new balance on a ledger. Every balance belongs to exactly one ledger. Pass the ledger and currency as flags when you already know them, or leave the flags off and answer the prompts. You can link an identity now, or later with `update`.

```bash blnk balances create
blnk balances create [options]
```

<SectionLabel icon="brackets">Arguments</SectionLabel>

Pass these as flags, or leave them off and answer the prompts. If you pass any flag and omit a required one, the CLI stops and names the missing flag.

| Argument | Type | Required | Description |
| :-- | :-- | :-- | :-- |
| `ledger_id` | string | Yes | Ledger ID for the balance. Flag: `--ledger-id`. Prompt: `ledger id >` |
| `currency` | string | Yes | Balance currency. Flag: `--currency`. Prompt: `currency >` |
| `identity_id` | string | No | Identity ID to link. Flag: `--identity-id`. Prompt: `identity id >` |
| `meta_data` | object | No | Metadata as JSON. Flag: `--metadata`. Prompt: `metadata (json) >`. Press **Enter** to skip. |

<SectionLabel icon="settings-2">Options</SectionLabel>

| Option | Type | Description |
| :-- | :-- | :-- |
| `--json` | boolean | After a successful create, print the full API response as JSON. |
| `-h, --help` | boolean | Show help for this command. |

<SectionLabel icon="list-ordered">Usage</SectionLabel>

<Steps>
<Step title="Create new balance">
```bash Create a balance wrap
blnk balances create --ledger-id ldg_abc123 --currency USD --json
blnk balances create
```

The CLI prompts for each argument:

```text Prompts wrap
currency >
ledger id >
identity id >
metadata (json) >
```

Press **Enter** at optional prompts to skip.

## `update`

Attach an identity to a balance that was created without one, or change the linked identity. Pass the balance ID on the command line. Pass `--identity-id` to skip the prompt, or leave it off and the CLI asks.

```bash blnk balances update
blnk balances update <balance-id> [options]
```

<SectionLabel icon="brackets">Arguments</SectionLabel>

| Argument | Type | Required | Description |
| :-- | :-- | :-- | :-- |
| `balance-id` | string | Yes | Balance ID to update (for example `bln_01dab2b7-3ec7-4253-b302-edd947423883`). Passed on the command line. |
| `identity_id` | string | Yes | Identity ID to link. |

<SectionLabel icon="settings-2">Options</SectionLabel>

| Option | Type | Description |
| :-- | :-- | :-- |
| `--identity-id` | string | Identity ID to link. Required when any flag is passed. |
| `--json` | boolean | Print the Core response as JSON. |
| `-h, --help` | boolean | Show help for this command. |

<SectionLabel icon="list-ordered">Usage</SectionLabel>

<Steps>
<Step title="Link balance to identity">
Run the command with a balance ID:

```bash Link an identity wrap
blnk balances update bln_01dab2b7-3ec7-4253-b302-edd947423883 --identity-id idt_fa2e58ba-9826-4614-9ba2-02b62df8c4d0 --json
blnk balances update bln_01dab2b7-3ec7-4253-b302-edd947423883
```

The CLI prompts for the identity to link:

```text Prompts wrap
identity id >
```
</Step>
<Step title="Read the updated balance">
```text JSON icon="check-circle"
Balance identity updated:
{
  "message": "Balance identity updated successfully"
}
```
</Step>
</Steps>

## `at`

Read a balance as it stood at a time, for example `2026-11-19T00:30:00Z`. Use this when you are checking a past position. Add `--from-source` when you want that figure rebuilt from the transactions rather than from a saved snapshot.

```bash Historical balance wrap
blnk balances at bln_01dab2b7-3ec7-4253-b302-edd947423883 --timestamp 2026-11-19T00:30:00Z --from-source --json
```

```text JSON icon="check-circle"
Balance at:
{
  "balance": {
    "balance": -1200,
    "balance_id": "bln_01dab2b7-3ec7-4253-b302-edd947423883",
    "credit_balance": 0,
    "currency": "USD",
    "debit_balance": 1200
  },
  "from_source": true,
  "timestamp": "2026-11-19T00:30:00Z"
}
```

## `lineage`

See where the funds on a balance came from. Use this when that balance is set up to track fund lineage. If it is not, Core tells you lineage is not enabled for that balance.

```bash Lineage wrap
blnk balances lineage bln_01dab2b7-3ec7-4253-b302-edd947423883 --json
```

## `snapshots`

Start the daily snapshots of your balances. Use this when you want a saved picture of every balance for the current day. Core writes one snapshot per balance and returns while that work continues.

```bash Snapshots wrap
blnk balances snapshots --batch-size 500 --json
```

```text JSON icon="check-circle"
Balance snapshots:
{
  "message": "Snapshotting in progress. should be completed shortly"
}
```
