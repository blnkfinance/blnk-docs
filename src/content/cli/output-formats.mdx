The Blnk CLI has no global `--format` flag; output depends on the command and flags you pass.

## Output modes

Use this table before you pipe output elsewhere.

| Mode | When you see it | Typical commands |
| :-- | :-- | :-- |
| **Table** | Paginated list with column headers and a footer | `blnk ledgers list`, `blnk balances list`, … |
| **Summary** | Labeled fields after create or single-resource fetch | `blnk ledgers create`, `blnk ledgers list --id ldg_…` |
| **JSON** | Pretty-printed API object | `--json` on list, create, update, metadata, snapshots, lineage, queue recover, and reconciliation commands |

## Table output

Resource `list` commands (without `--id`) render an ASCII table with column headers, then a footer with total results and page number. Tables are meant for scanning many records in the terminal, not for machine parsing.

## Summary output

After `create` or when you run `list --id` without `--json`, the CLI prints a short labeled block with the fields most people need day to day. This is the default human-readable detail view; switch to JSON when you need every API field.

```text 200 Success icon="check-circle"
Ledger details:
  name: EUR Operations
  ledger_id: ldg_46074f0e-898d-4b48-bced-d647816168c0
  created_at: 2026-05-23T17:07:49Z
```

## JSON output

Pass `--json` to print the Core response as JSON instead of the table or summary. Use it when you are checking a result against your application, or when you want to pass the output to another tool.

List commands that accept `--json` are ledgers, balances, transactions, identities, and reconciliations.

```bash Fetch one ledger wrap
blnk ledgers list --id ldg_46074f0e-898d-4b48-bced-d647816168c0 --json
```

```text 200 Success icon="check-circle"
{
  "ledger_id": "ldg_46074f0e-898d-4b48-bced-d647816168c0",
  "name": "EUR Operations",
  "created_at": "2026-05-23T17:07:49.876192Z",
  "meta_data": {
    "currency_focus": "EUR",
    "region": "EU"
  }
}
```
