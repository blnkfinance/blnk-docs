The Blnk CLI is the official command-line tool to interact with your Blnk Core. Use it to [connect to an instance](/cli/using-blnk-core) and manage ledgers, balances, transactions, identities, and reconciliations from your terminal. 

Browse commands in the sidebar under [Resource commands](/cli/ledgers) and [Additional commands](/cli/help).

## Install and update

<Version>Latest version: 1.8.3.</Version>

You need [Node.js](https://nodejs.org/) 18 or later, and [npm](https://www.npmjs.com/package/@blnkfinance/blnk-cli), on your machine. Install and update the Blnk CLI globally:

```bash Install
npm i -g @blnkfinance/blnk-cli
```

Confirm your installation:

```bash Check the version
blnk --version
```

```text 200 Success icon="check-circle"
Blnk CLI:
  1.8.3
```
