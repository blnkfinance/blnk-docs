Update metadata on an existing ledger, balance, transaction, or identity without recreating the record.

| Command | Alias | Description |
| :-- | :-- | :-- |
| update | u | Replace the extra details on one record |

## `update`

Pass the record ID and the new metadata. The ID tells the CLI what you are updating: ledgers begin with `ldg_`, balances with `bln_`, transactions with `txn_`, and identities with `idt_`. The metadata must be an object, such as a region or a channel.

```bash blnk metadata update
blnk metadata update <id> --metadata <json> [options]
```

<SectionLabel icon="brackets">Arguments</SectionLabel>

| Argument | Type | Required | Description |
| :-- | :-- | :-- | :-- |
| `id` | string | Yes | Record ID starting with `ldg_`, `bln_`, `txn_`, or `idt_`. |

<SectionLabel icon="settings-2">Options</SectionLabel>

| Option | Type | Required | Description |
| :-- | :-- | :-- | :-- |
| `--metadata` | json | Yes | Metadata object to set. |
| `--json` | boolean | No | Print the Core response as JSON. |
| `-h, --help` | boolean | No | Show help for this command. |

<SectionLabel icon="list-ordered">Usage</SectionLabel>

<Steps>
<Step title="Update metadata">
```bash Update wrap
blnk metadata update ldg_abc123 --metadata '{"region":"EU"}' --json
blnk metadata update bln_abc123 --metadata '{"channel":"cli"}'
```
</Step>
</Steps>

An unknown prefix or metadata that is not a JSON object fails before Core.
