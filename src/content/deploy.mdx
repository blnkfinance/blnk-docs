Blnk ships as two versions, and you choose where each one runs. Open-source is Core under the open-source license, and you host it.

Enterprise and Blnk Cloud include every module. You host Enterprise with a license, and we host Blnk Cloud, where Sandbox and Production are tiers of that same product.

## Modules

- **Core.** The ledger: ledgers, balances, transactions, reconciliation, identities, and the rest of the Core API.
- **Cloud.** The dashboard: back office, team access, audit logs, alerts, and apps.
- **Watch.** Transaction monitoring.
- **Insights.** SQL reporting on the data lake.

## Open-source

You host Core on infrastructure you control, under the open-source license. Cloud, Watch, and Insights are not part of this deployment. When you are ready to run a server, follow [Open-source](/deploy/open-source).

## Enterprise

You host Core, Cloud, Watch, and Insights on your own infrastructure. The license comes from [sales](https://blnkfinance.com/contact/us?utm_source=blnk_docs&utm_medium=documentation&utm_campaign=deploy), and the dashboard does not start without the key they send. Follow [Enterprise](/deploy/enterprise) once you have it.

## Blnk Cloud

We host every module, the same set as Enterprise. You sign up, then deploy a managed instance from the workspace, as Sandbox or Production. Follow [Blnk Cloud](/deploy/blnk-cloud) for that deploy.
