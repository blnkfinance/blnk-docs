Blnk can deploy in one of two ways: self-hosted or managed hosting on Blnk Cloud. 

Depending on your requirements, you can choose the best hosting option for your use case.

## Self hosting

Self hosting means you host Blnk on your own infrastructure with full control over your data and environment. How much of Blnk you can use is determined by the license you have.

We offer two licenses: Open-source Core and Enterprise Core.

<Tabs>
  <Tab title="Open-source Core" icon="github">

The open-source Core is free under the [Apache License 2.0](https://github.com/blnkfinance/blnk/blob/main/LICENSE). 

```bash Install Open-source
docker pull ghcr.io/blnkfinance/blnk:latest
```

It includes:

- Ledgers
- Balances
- Transactions
- Reconciliation
- Identities

See deployment details in the [Open-source deploy guide](/deploy/open-source).

  </Tab>
  <Tab title="Enterprise Core" icon="building-1">

Enterprise Core adds enterprise features on top of the open-source Core: 

- Role-based access (RBAC)
- SQL-based data lake
- Alerts
- Audit logs
- MCP
- Agents
- Dashboard with extensible UI

```bash Install Enterprise
docker pull ghcr.io/blnkfinance/blnk:latest
docker pull ghcr.io/blnkfinance/blnk-enterprise:latest
```

<Note>You'll need to acquire an Enterprise license to self-host our Enterprise Core.</Note>

See deployment details in the [Enterprise deploy guide](/deploy/enterprise).

  </Tab>
</Tabs>

## Blnk Cloud

Blnk Cloud is a managed hosting service that hosts your ledger on Blnk Cloud infrastructure. It's a fully managed service that requires no infrastructure setup on your part.

We provide both Sandbox and Production environments for you to explore and run your ledger in production.

<Tip>
Blnk Cloud gives you full access to the open-source Core and all the features of the Enterprise Core.
</Tip>

It's a great option if you want to get started quickly and don't want to worry about the underlying infrastructure.

To learn more about managed hosting and available regions, see the [Blnk Cloud deploy guide](/deploy/blnk-cloud).
