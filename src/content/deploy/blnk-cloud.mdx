Blnk Cloud hosts the open-source Core and the Enterprise Core features for you. You deploy a managed instance from a workspace, and Sandbox and Production are the two hosting tiers.

## Sandbox and Production

Both tiers include the same modules. They differ in the infrastructure under the instance.

| | Sandbox | Production |
| :--- | :--- | :--- |
| Infrastructure | Shared | Dedicated |
| Throughput | Up to 5,000 transactions a minute | Up to 100,000 transactions a minute |
| Uptime | No SLA | 99.9% |
| Backups and high availability | Not included | Included |
| Data lake | Not included | Included |

## Deploy an instance

<Steps>
<Step title="Sign up">

Create a workspace at [cloud.blnkfinance.com](https://cloud.blnkfinance.com/auth/sign-up?utm_source=blnk_docs&utm_medium=documentation&utm_campaign=deploy%2Fblnk-cloud). The deploy runs inside that workspace.

</Step>

<Step title="Open the deploy form">

On the homepage, click **Deploy new Core**. The same form opens from **Deploy an instance** in the header.

![Blnk Cloud homepage with Deploy new Core](img/home/cloud-home.png)

</Step>

<Step title="Deploy the instance">

- **Instance name:** a name you will recognize, such as `blnk-sandbox`
- **Deploy Managed Core:** selected, so Blnk hosts Core
- **Deploy type:** `Sandbox` or `Production`
- **Region:** the region closest to your application

Accept the Service Level Agreement, then click **Deploy instance**.

![Deploy an instance form with deploy type and region](img/home/managed-instance-form.png)

</Step>

<Step title="Wait until it is connected">

Sandbox usually finishes in 7–10 minutes, and Production can take 10–30 minutes.

</Step>
</Steps>

When the status is **Connected**, open the instance and copy the Core URL and secret key. Use that URL for Core API requests, and send the secret key as `X-blnk-key`.
