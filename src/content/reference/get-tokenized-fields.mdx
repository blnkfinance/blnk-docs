<Key />

<Version>Available in version 0.8.8 and later.</Version>

### Path

<ParamField path="identity_id" type="string" required>
  Id of the identity to inspect.
</ParamField>

### Response

<ResponseField name="tokenized_fields" type="string[]" required>
  PascalCase names that are tokenized on this identity.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "http://localhost:5001/identities/{identity_id}/tokenized-fields" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "tokenized_fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"]
}
```

```json 404 Not Found
{
  "error": "Identity with ID 'idt_c415a4dc-4231-453d-a837-a9a50b1070e0' not found",
  "error_detail": {
    "code": "IDT_NOT_FOUND",
    "message": "Identity with ID 'idt_c415a4dc-4231-453d-a837-a9a50b1070e0' not found"
  }
}
```

</ResponseExample>
