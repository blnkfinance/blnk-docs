Delete a custom role.

<Warning>
The call fails if any member still has that identifier. Reassign them with [Assign role](/reference/assign-role) first.
</Warning>

<Authorization />

### Path

<ParamField path="role_id" type="string" required>
  Id of the custom role (`role_...`).
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE "https://api.cloud.blnkfinance.com/organizations/roles/role_8f2c1a40-6b1e-4d3a-9c70-1e5a2b4d8f16" \
  -H "X-blnk-key: CLOUD_API_KEY"
```

</RequestExample>
