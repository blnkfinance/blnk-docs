The Blnk MCP server exposes a Core instance through the [Model Context Protocol](https://modelcontextprotocol.io/). Cursor, Claude Desktop, and ChatGPT connect to Cloud, and Cloud forwards authorized tool calls to that instance.

Clients do not open a connection to Core. Cloud checks the credential, enforces `mcp:read` and `mcp:write`, and sends the operation to the instance in the URL.

<RequestExample>

```json MCP configuration
{
  "mcpServers": {
    "blnk": {
      "url": "https://api.cloud.blnkfinance.com/mcp/YOUR_INSTANCE_ID",
      "headers": {
        "X-blnk-key": "CLOUD_API_KEY"
      }
    }
  }
}
```

</RequestExample>

## Set up your client

<Steps>
<Step title="Create credentials">
Create an [API key](/reference/enterprise-api-key) or an [OAuth client](/reference/oauth). Both need `mcp:read` and `mcp:write`.
</Step>
<Step title="Copy the MCP endpoint">
Open **Settings > MCP** and copy the configuration for the instance.

<Tabs>
<Tab title="API key">

```json API key
{
  "mcpServers": {
    "blnk": {
      "url": "https://api.cloud.blnkfinance.com/mcp/YOUR_INSTANCE_ID",
      "headers": {
        "X-blnk-key": "CLOUD_API_KEY"
      }
    }
  }
}
```

</Tab>
<Tab title="OAuth">
Use the endpoint URL with your OAuth client id and client secret. The client signs in. You do not put a Cloud API key in the config.

```text Endpoint
https://api.cloud.blnkfinance.com/mcp/YOUR_INSTANCE_ID
```

</Tab>
</Tabs>
</Step>
<Step title="Add the server to the client">
<Tabs>
<Tab title="Cursor">
Open Cursor settings, go to **MCP**, and add the server. Paste the JSON for an API key, or the endpoint URL for OAuth.
</Tab>
<Tab title="Claude Desktop">
Add the configuration to `claude_desktop_config.json`.

```bash macOS
~/Library/Application Support/Claude/claude_desktop_config.json
```

```bash Windows
%APPDATA%\Claude\claude_desktop_config.json
```

</Tab>
<Tab title="ChatGPT">
Go to **Settings > Apps**. Open **Advanced settings**, enable **Developer mode**, and click **Create app**.

![ChatGPT MCP app form with name, server URL, and OAuth fields](img/cloud/chatgpt-setup.png)

- **Name:** A name such as Blnk MCP.
- **MCP Server URL:** The endpoint from the previous step.
- **Authentication:** OAuth, then the client id and client secret.

Click **Create** and sign in to Blnk Cloud when asked.
</Tab>
</Tabs>
</Step>
<Step title="Ask about the ledger">
The client can read and update ledger data through the tools below.
</Step>
</Steps>

## What you can ask

- **Activity:** Transactions from the last 24 hours, or what changed since yesterday.
- **Balances:** The balance for a wallet, or balances that are negative or low.
- **Failures:** Failed or voided transactions, or a transaction by reference.
- **Large movements:** USD transactions over \$5,000, or unusually large transactions today.
- **Totals:** How much moved today, or the total across customer wallets.
- **Lake:** The lake schema, a count of `APPLIED` transactions last month, or a saved query on a daily schedule.
- **Workflows:** A balance monitor, a bulk inflight commit, or a reconciliation run.

## Response

Blnk MCP follows the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-03-26). Message shape, session lifecycle, transport, and errors are defined there. Most clients handle that for you.
