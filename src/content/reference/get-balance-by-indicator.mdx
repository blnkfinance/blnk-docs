<Key />

### Path

<Version>Available in version 0.10.3 and later.</Version>

<ParamField path="indicator" type="string" required>
  Specifies the indicator of the balance being retrieved.
</ParamField>

<ParamField path="currency" type="string" required>
  Specifies the currency of the balance being retrieved.
</ParamField>

<RequestExample>

```bash cURL
curl -X GET "http://localhost:5001/balances/indicator/{indicator}/currency/{currency}" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>
