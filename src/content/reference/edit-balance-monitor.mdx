<Key />

### Path

<ParamField path="monitor_id" type="string" required>
  The unique id of the balance monitor to update.
</ParamField>

### Body

<ParamField body="balance_id" type="string" required>
  Specifies the balance id of the ledger balance to be monitored.
</ParamField>

<ParamField body="condition" type="object" required>
  Defines the criteria for monitoring a specific balance type.
  <Expandable>
    <ParamField body="field" type="string" required>
      Specifies the balance type to be monitored. Every ledger balance has 6 balance types - `balance`, `inflight_balance`, `credit_balance`, `inflight_credit_balance`, `debit_balance`, and `inflight_debit_balance`.
    </ParamField>
    <ParamField body="operator" type="string" required>
      Comparison to apply: `>`, `<`, `>=`, `<=`, `=`, or `!=`.
    </ParamField>
    <ParamField body="value" type="number" required>
      Threshold in major units. `0` and fractions such as `100.50` are valid. The PUT writes this value as sent, including `0` when the field is omitted.
    </ParamField>
    <ParamField body="precision" type="number">
      Scale for `value`. Omit it to keep the stored precision. A sent precision is written, and `precise_value` is recomputed.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="trigger" type="string">
  How you want the monitor to behave. `edge` notifies you once when the rule first matches, then stays quiet until the amount no longer matches. 
  
  `level` notifies you on every transaction that updates the balance while the rule still matches.
</ParamField>

<ParamField body="description" type="string">
  A brief explanation of the purpose of the monitor. The PUT writes this as sent.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  Confirms the monitor was updated.
</ResponseField>

<RequestExample>

```bash cURL
curl -X PUT "http://localhost:5001/balance-monitors/{monitor_id}" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "balance_id": "bln_0be360ca-86fe-457d-be43-daa3f966d8f0",
    "trigger": "level",
    "condition": {
      "field": "debit_balance",
      "operator": ">",
      "value": 1000,
      "precision": 100
    }
  }'
```

</RequestExample>

```json 200 OK
{
```

```json 404 Not Found
}
```

</ResponseExample>
