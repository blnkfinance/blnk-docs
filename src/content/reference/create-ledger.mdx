---
title: "Create ledger"
description: "How to create a new ledger in Blnk."
method: "POST"
path: "/ledgers"
noindex: true
---
<Key />

### Body

<ParamField body="name" type="string" required>
  Name of the ledger. Ensure it is as descriptive as possible for easy reference.
</ParamField>

<ParamField body="meta_data" type="object">
  Additional metadata for the request body.
</ParamField>

### Response

<ResponseField name="ledger_id" type="string" required>
  Unique id to represent the created ledger.
</ResponseField>

<ResponseField name="name" type="string" required>
  Name of the ledger.
</ResponseField>

<ResponseField name="created_at" type="string" required>
  Indicates the date & time of creation.
</ResponseField>

<ResponseField name="meta_data" type="User Object">
  Additional metadata of the ledger.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "http://localhost:5001/ledgers" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Customer Savings Ledger",
    "meta_data": {
      "project_owner": "Acme LLC",
      "description": "For all savings account created & managed by Acme."
    }
  }'
```

</RequestExample>

<ResponseExample>

```json 201 Created
{
  "ledger_id": "ldg_073f7ffe-9dfd-42ce-aa50-d1dca1788adc",
  "name": "Customer Savings Ledger",
  "created_at": "2024-02-20T05:28:03.558281542Z",
  "meta_data": {
    "project_owner": "Acme LLC",
    "description": "For all savings account created & managed by Acme."
  }
}
```

```json 409 Conflict
{
  "error": "Ledger with this name or ID already exists",
  "error_detail": {
    "code": "LGR_DUPLICATE",
    "message": "Ledger with this name or ID already exists"
  }
}
```

</ResponseExample>
