<Key />

### Path
<ParamField path="transaction_id" type="string" required>
  Specifies the unique ID of the transaction record being retrieved. Leave empty to view all transactions in your Blnk Ledger.
</ParamField>

<RequestExample>
```bash cURL
curl -X GET "http://localhost:5001/transactions/{transaction_id}" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>
