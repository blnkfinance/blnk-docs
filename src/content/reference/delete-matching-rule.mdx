---
title: "Delete matching rule"
description: "Remove a matching rule."
method: "DELETE"
path: "/reconciliation/matching-rules/{rule_id}"
noindex: true
---
<Key />

### Path

<ParamField path="rule_id" type="string" required>
  Id of the rule to delete. An unknown id returns `404` with `RECON_RULE_NOT_FOUND`.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  `Matching rule deleted successfully`.
</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE "http://localhost:5001/reconciliation/matching-rules/rule_890bdbc4-467f-4670-8424-5667e41daf29" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "message": "Matching rule deleted successfully"
}
```

```json 404 Not Found
{
  "error": "Matching rule with ID 'rule_00000000-0000-0000-0000-000000000000' not found",
  "error_detail": {
    "code": "RECON_RULE_NOT_FOUND",
    "message": "Matching rule with ID 'rule_00000000-0000-0000-0000-000000000000' not found"
  }
}
```

</ResponseExample>
