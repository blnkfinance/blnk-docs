<Key />

Send the file as multipart form data. See [External data](/reconciliations/external-data) for the row format.

### Body

<ParamField body="file" type="file" required>
  CSV, or a JSON array of records. A missing file returns `400` with `RECON_UPLOAD_FAILED`. A file Core cannot parse or store, including a duplicate `id`, returns `500` with `RECON_UPLOAD_PROCESSING_FAILED`.
</ParamField>

<ParamField body="source" type="string">
  Name copied onto every stored row, such as `Stripe`. A source column in the file is not kept.
</ParamField>

### Response

<ResponseField name="upload_id" type="string" required>
  Id of the upload. Pass it as `upload_id` to [Start reconciliation](/reference/start-reconciliation).
</ResponseField>

<ResponseField name="record_count" type="integer" required>
  How many rows were stored.
</ResponseField>

<ResponseField name="source" type="string" required>
  The source name you sent.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "http://localhost:5001/reconciliation/upload" \
  -H "X-blnk-key: <api-key>" \
  -F "file=@transactions.json" \
  -F "source=Stripe"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "upload_id": "upload_8c700d1b-09c0-4ef4-9ab1-a0decf3d0aa3",
  "record_count": 1000,
  "source": "Stripe"
}
```

```json 400 Bad Request
{
  "error": "File upload failed",
  "error_detail": {
    "code": "RECON_UPLOAD_FAILED",
    "message": "File upload failed"
  }
}
```

</ResponseExample>
