---
title: "Delete metadata template"
description: "Delete a metadata template from your organization."
method: "DELETE"
path: "/data/metadata-templates/{metadata_template_id}"
enterprise: license
noindex: true
---
This endpoint deletes a metadata template. Records that already used it keep their metadata. The template just stops showing up under **Use template**.

<Authorization />

### Path

<ParamField path="metadata_template_id" type="string" required>
Unique id of the template (`metadata_template_...`). Get it from [List metadata templates](/reference/list-metadata-templates) or [Create metadata template](/reference/create-metadata-template).
</ParamField>

### Response

Returns `204 No Content` with an empty body.

<RequestExample>

```bash cURL
curl -X DELETE 'https://api.cloud.blnkfinance.com/data/metadata-templates/metadata_template_7c1e9a42-5b3d-4f8e-9a61-2d4c8b0e3f57' \
  -H 'X-blnk-key: CLOUD_API_KEY'
```
</RequestExample>

<ResponseExample>

```text 204 No Content
(empty body)
```

```json 404 Not Found
{
  "error": "Metadata template not found"
}
```
</ResponseExample>
