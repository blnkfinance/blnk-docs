<Key />

### Body

<ParamField body="identity_id" type="string">
  Your own identity id. When you send it, it must start with `idt_` and a valid UUID, for example `idt_11111111-1111-4111-8111-111111111111`. Leave it out and Blnk generates one. A duplicate id returns `400` with `IDT_VALIDATION_ERROR`.
</ParamField>

<ParamField body="identity_type" type="string">
  `individual` or `organization`.
</ParamField>

<ParamField body="organization_name" type="string">
  Name of the organization.
</ParamField>

<ParamField body="first_name" type="string">
  First name of the individual.
</ParamField>

<ParamField body="last_name" type="string">
  Last name of the individual.
</ParamField>

<ParamField body="other_names" type="string">
  Other names linked to the individual.
</ParamField>

<ParamField body="gender" type="string">
  Gender of the individual.
</ParamField>

<ParamField body="dob" type="string">
  Date of birth, as an ISO 8601 timestamp.
</ParamField>

<ParamField body="email_address" type="string">
  Email address of the identity.
</ParamField>

<ParamField body="phone_number" type="string">
  Contact number of the identity.
</ParamField>

<ParamField body="nationality" type="string">
  Nationality of the individual.
</ParamField>

<ParamField body="category" type="string">
  A label for this customer, such as `customer` or `vip`.
</ParamField>

<ParamField body="street" type="string">
  Street address of the identity.
</ParamField>

<ParamField body="country" type="string">
  Country of the identity.
</ParamField>

<ParamField body="state" type="string">
  State or region of the identity.
</ParamField>

<ParamField body="post_code" type="string">
  Postal code of the identity.
</ParamField>

<ParamField body="city" type="string">
  City of the identity.
</ParamField>

<ParamField body="meta_data" type="object">
  Custom metadata linked to the identity.
</ParamField>

### Response

The response is the identity Blnk stored. `created_at` is set by Blnk. A field you omit comes back empty.

<ResponseField name="identity_id" type="string" required>
  Id of the created identity.
</ResponseField>

<ResponseField name="identity_type" type="string">

</ResponseField>

</ResponseField>

  Gender of the individual.

  Date of birth.

<ResponseField name="email_address" type="string">
  Email address of the identity.

<RequestExample>

```bash cURL
curl -X POST "http://localhost:5001/identities" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "identity_id": "idt_11111111-1111-4111-8111-111111111111",
    "identity_type": "individual",
    "first_name": "Alice",
    "last_name": "Smith",
    "other_names": "Marie",
    "gender": "female",
    "dob": "1985-05-15T00:00:00Z",
    "email_address": "alice.smith@example.com",
    "phone_number": "+1234567890",
    "nationality": "Canadian",
    "category": "customer",
    "street": "789 Elm St",
    "country": "Canada",
    "state": "Ontario",
    "post_code": "M4B 1B3",
    "city": "Toronto",
    "meta_data": {
      "customer_id": "CUST123456",
      "membership_level": "Gold"
    }
  }'
```

</RequestExample>
