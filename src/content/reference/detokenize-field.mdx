---
title: "Detokenize one field"
description: "Read the original value of one tokenized identity field."
method: "GET"
path: "/identities/{identity_id}/detokenize/{field}"
noindex: true
---
<Key />

<Version>Available in version 0.8.8 and later.</Version>

The identity keeps the token. This call only returns the original value.

### Path

<ParamField path="identity_id" type="string" required>
  Id of the identity that holds the token.
</ParamField>

<ParamField path="field" type="string" required>
  PascalCase name of the field to read: `FirstName`, `LastName`, `OtherNames`, `EmailAddress`, `PhoneNumber`, `Street`, or `PostCode`.
</ParamField>

### Response

<ResponseField name="field" type="string" required>
  PascalCase name you asked for.
</ResponseField>

<ResponseField name="value" type="string" required>
  Original value of that field.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "http://localhost:5001/identities/{identity_id}/detokenize/EmailAddress" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "field": "EmailAddress",
  "value": "alice.smith@example.com"
}
```

```json 400 Bad Request
{
  "error": "field EmailAddress is not tokenized",
  "error_detail": {
    "code": "IDT_FIELD_NOT_TOKENIZED",
    "message": "field EmailAddress is not tokenized"
  }
}
```

</ResponseExample>
