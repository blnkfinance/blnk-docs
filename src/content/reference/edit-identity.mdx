---
title: "Edit identity"
description: "Update the fields stored on an identity."
seoTitle: "Edit Identity • Blnk API Reference"
method: "PUT"
path: "/identities/{identity_id}"
noindex: true
---

<Key />

Send only the fields you want to change. Blnk skips an empty string, so the stored value stays. When you send `meta_data`, it replaces the object stored on the identity. A body with no fields returns `400`.

### Path

<ParamField path="identity_id" type="string" required>
  Id of the identity to update.
</ParamField>

### Body

<ParamField body="identity_type" type="string">
  `individual` or `organization`.
</ParamField>

<ParamField body="organization_name" type="string">
  Name of the organization.
</ParamField>

<ParamField body="first_name" type="string">
  First name of the individual.
</ParamField>

<ParamField body="last_name" type="string">
  Last name of the individual.
</ParamField>

<ParamField body="other_names" type="string">
  Other names linked to the individual.
</ParamField>

<ParamField body="gender" type="string">
  Gender of the individual.
</ParamField>

<ParamField body="dob" type="string">
  Date of birth, as an ISO 8601 timestamp.
</ParamField>

<ParamField body="email_address" type="string">
  Email address of the identity.
</ParamField>

<ParamField body="phone_number" type="string">
  Contact number of the identity.
</ParamField>

<ParamField body="nationality" type="string">
  Nationality of the individual.
</ParamField>

<ParamField body="category" type="string">
  A label for this customer, such as `customer` or `vip`.
</ParamField>

<ParamField body="street" type="string">
  Street address of the identity.
</ParamField>

<ParamField body="country" type="string">
  Country of the identity.
</ParamField>

<ParamField body="state" type="string">
  State or region of the identity.
</ParamField>

<ParamField body="post_code" type="string">
  Postal code of the identity.
</ParamField>

<ParamField body="city" type="string">
  City of the identity.
</ParamField>

<ParamField body="meta_data" type="object">
  Custom metadata. Replaces the object stored on the identity.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  Confirms the identity was updated.
</ResponseField>

<RequestExample>

```bash cURL
curl -X PUT "http://localhost:5001/identities/{identity_id}" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "email_address": "alice.smith@example.com",
    "phone_number": "+1234567890"
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "message": "Identity updated successfully"
}
```

```json 400 Bad Request
{
  "error": "No fields provided for update",
  "error_detail": {
    "code": "GEN_BAD_REQUEST",
    "message": "No fields provided for update"
  }
}
```

```json 404 Not Found
{
  "error": "Identity with ID 'idt_c415a4dc-4231-453d-a837-a9a50b1070e0' not found",
  "error_detail": {
    "code": "IDT_NOT_FOUND",
    "message": "Identity with ID 'idt_c415a4dc-4231-453d-a837-a9a50b1070e0' not found"
  }
}
```

</ResponseExample>
