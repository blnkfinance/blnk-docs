Create OAuth token exchanges an authorization code for an access token, or refreshes an access token. Start sign-in with [Authorize OAuth](/reference/authorize-client).

Send this request to `https://api.cloud.blnkfinance.com` on Blnk Cloud. On a self-hosted Enterprise deployment, send it to `ENTERPRISE_PUBLIC_URL`.

Send the client id and client secret as HTTP Basic, or in the body as `client_id` and `client_secret`. The body is form fields or JSON.

The access token lasts 1 hour. Send it as `X-blnk-key` on Enterprise API requests.

A refresh returns a new access token and a new refresh token, and the previous refresh token stops working. The refresh token lasts 30 days.

### Header

<ParamField header="Authorization" type="string">
  HTTP Basic credentials, `Basic base64(client_id:client_secret)`. Omit this when `client_id` and `client_secret` are in the body.
</ParamField>

### Body

<ParamField body="grant_type" type="string" required>
  `authorization_code` or `refresh_token`.
</ParamField>

<ParamField body="code" type="string">
  Authorization code from [Authorize OAuth](/reference/authorize-client). Required when `grant_type` is `authorization_code`. The code lasts 10 minutes and works once.
</ParamField>

<ParamField body="redirect_uri" type="string">
  The same `redirect_uri` used to authorize. Required when `grant_type` is `authorization_code`.
</ParamField>

<ParamField body="refresh_token" type="string">
  Refresh token from an earlier response (`blnk_rt_...`). Required when `grant_type` is `refresh_token`.
</ParamField>

<ParamField body="client_id" type="string">
  Client id. Required when you do not send the `Authorization` header.
</ParamField>

<ParamField body="client_secret" type="string">
  Client secret. Required when you do not send the `Authorization` header.
</ParamField>

<ParamField body="code_verifier" type="string">
  PKCE verifier. Required when the authorization request included `code_challenge`.
</ParamField>

### Response

A `200` response returns the tokens. Save `access_token` and `refresh_token`. Invalid client credentials return `401` with `invalid_client`.

<ResponseField name="access_token" type="string" required>
  Access token (`blnk_at_...`). Send it as `X-blnk-key`.
</ResponseField>

<ResponseField name="token_type" type="string" required>
  `Bearer`.
</ResponseField>

<ResponseField name="expires_in" type="integer" required>
  Seconds until the access token expires. `3600`.
</ResponseField>

<ResponseField name="refresh_token" type="string" required>
  Refresh token (`blnk_rt_...`). Each refresh replaces this value.
</ResponseField>

<ResponseField name="scope" type="string">
  Space-separated scopes on the token.
</ResponseField>

<RequestExample>

```bash Authorization code
curl -X POST "https://api.cloud.blnkfinance.com/oauth/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -u "YOUR_CLIENT_ID:YOUR_CLIENT_SECRET" \
  -d "grant_type=authorization_code" \
  -d "code=THE_CODE_FROM_REDIRECT" \
  -d "redirect_uri=https://your-app.com/oauth/callback"
```

```bash Refresh token
curl -X POST "https://api.cloud.blnkfinance.com/oauth/token" \
  -H "Content-Type: application/x-www-form-urlencoded" \
  -u "YOUR_CLIENT_ID:YOUR_CLIENT_SECRET" \
  -d "grant_type=refresh_token" \
  -d "refresh_token=blnk_rt_YOUR_REFRESH_TOKEN_HERE"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "access_token": "blnk_at_...",
  "token_type": "Bearer",
  "expires_in": 3600,
  "refresh_token": "blnk_rt_...",
  "scope": "data:read data:write proxy:write"
}
```

```json 400 Bad Request
{
  "error": "invalid_grant",
  "error_description": "invalid authorization code"
}
```

</ResponseExample>
