---
title: "Get metadata template"
description: "Return one metadata template and its keys."
method: "GET"
path: "/data/metadata-templates/{metadata_template_id}"
enterprise: license
noindex: true
---
This endpoint returns one metadata template by `metadata_template_id`, including its keys.

<Authorization />

### Path

<ParamField path="metadata_template_id" type="string" required>
Unique id of the template (`metadata_template_...`). Get it from [List metadata templates](/reference/list-metadata-templates) or [Create metadata template](/reference/create-metadata-template).
</ParamField>

### Response

<ResponseField name="metadata_template_id" type="string">
Unique id of the template (`metadata_template_...`). Use it to get, update, or delete the template.
</ResponseField>

<ResponseField name="name" type="string">
Template name. Unique within your organization.
</ResponseField>

<ResponseField name="description" type="string">
Note on when to use the template. Empty string when none was set.
</ResponseField>

<ResponseField name="keys" type="string[]">
Metadata keys the template adds to a form, in the order you sent them.
</ResponseField>

<ResponseField name="org_id" type="string">
Organization the template belongs to. Templates are shared across every instance in the organization.
</ResponseField>

<ResponseField name="created_at" type="timestamp">
When the template was created.
</ResponseField>

<ResponseField name="updated_at" type="timestamp">
When the name, description, or keys last changed.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET 'https://api.cloud.blnkfinance.com/data/metadata-templates/metadata_template_7c1e9a42-5b3d-4f8e-9a61-2d4c8b0e3f57' \
  -H 'X-blnk-key: CLOUD_API_KEY'
```
</RequestExample>
