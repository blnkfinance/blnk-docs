---
title: "Delete hooks"
sidebarTitle: "Delete hooks"
description: "Remove a hook by its ID."
method: "DELETE"
path: "/hooks/{hook_id}"
noindex: true
---

<Version>Available in version 0.8.4 or later.</Version>

<Warning>
Send the master key (`server.secret_key`) in the `X-blnk-key` header. Regular API keys return `403 Forbidden`.
</Warning>

### Path

<ParamField path="hook_id" type="string" required>
  Unique identifier of the hook
</ParamField>

<ResponseExample>
```json 403 Forbidden
{
  "error": "hook management requires master key",
  "error_detail": {
    "code": "AUTH_MASTER_KEY_REQUIRED",
    "message": "hook management requires master key"
  }
}
```
</ResponseExample>
