---
title: "Delete identity"
description: "Delete an identity from your ledger."
method: "DELETE"
path: "/identities/{identity_id}"
noindex: true
---
<Key />

### Path

<ParamField path="identity_id" type="string" required>
  Id of the identity to delete.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  Confirms the identity was deleted.
</ResponseField>

<RequestExample>

```bash cURL
curl -X DELETE "http://localhost:5001/identities/{identity_id}" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "message": "Identity deleted successfully"
}
```

```json 404 Not Found
{
  "error": "Identity with ID 'idt_c415a4dc-4231-453d-a837-a9a50b1070e0' not found",
  "error_detail": {
    "code": "IDT_NOT_FOUND",
    "message": "Identity with ID 'idt_c415a4dc-4231-453d-a837-a9a50b1070e0' not found"
  }
}
```

</ResponseExample>
