<Key />

### Body

<ParamField body="balance_id" type="string" required>
  Specifies the balance id of the ledger balance to be monitored.
</ParamField>

<ParamField body="condition" type="object" required>
  Defines the criteria for monitoring a specific balance type.
  <Expandable>
    <ParamField body="field" type="string" required>
      Specifies the balance type to be monitored. Every ledger balance has 6 balance types - `balance`, `inflight_balance`, `credit_balance`, `inflight_credit_balance`, `debit_balance`, and `inflight_debit_balance`.
    </ParamField>
    <ParamField body="operator" type="string" required>
      Comparison to apply: `>`, `<`, `>=`, `<=`, `=`, or `!=`. An operator outside this list returns `400 GEN_VALIDATION_ERROR`.
    </ParamField>
    <ParamField body="value" type="number" required>
      Threshold in major units. `0` and fractions such as `100.50` are valid. Blnk multiplies `value` by `precision` and compares the balance to that minor-unit amount.
    </ParamField>
    <ParamField body="precision" type="number" required>
      Scale for `value`, the same precision you use when recording that currency. Must be greater than `0`.
    </ParamField>
  </Expandable>
</ParamField>

<ParamField body="trigger" type="string" default="edge">
  How you want the monitor to behave. `edge` notifies you once when the rule first matches, then stays quiet until the amount no longer matches. 
  
  `level` notifies you on every transaction that updates the balance while the rule still matches.
</ParamField>

<ParamField body="description" type="string">
  A brief explanation of the purpose of the monitor.
</ParamField>

### Response

<ResponseField name="monitor_id" type="string">
  The unique id of the balance monitor.
</ResponseField>

<ResponseField name="trigger" type="string">
  `edge` or `level`.
</ResponseField>

<ResponseField name="condition_state" type="boolean">
  Last value of the condition. Present when `trigger` is `edge`. Omitted when `trigger` is `level`.
</ResponseField>

<ResponseField name="created_at" type="string">
  Date and time when the monitor was created.
</ResponseField>

<ResponseField name="condition.precise_value" type="number">
  Minor units Blnk compares against. `value` multiplied by `precision`.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "http://localhost:5001/balance-monitors" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "balance_id": "bln_0be360ca-86fe-457d-be43-daa3f966d8f0",
    "trigger": "edge",
    "condition": {
      "field": "debit_balance",
      "operator": ">",
      "value": 1000,
      "precision": 100
    }
  }'
```

</RequestExample>
