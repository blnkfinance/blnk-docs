title: "View list of hooks by type"

description: "List hooks, optionally filtered by type."
method: "GET"
path: "/hooks"
noindex: true
---

<Version>Available in version 0.8.4 or later.</Version>

<Warning>
Send the master key (`server.secret_key`) in the `X-blnk-key` header. Regular API keys return `403 Forbidden`.
</Warning>

### Query
<ParamField query="type" type="string">
  Filter by hook type: `PRE_TRANSACTION` or `POST_TRANSACTION`. Omit to return both types.

  ```
  GET http://localhost:5001/hooks?type=PRE_TRANSACTION
  ```
</ParamField>

<ResponseExample>
```json 403 Forbidden
{
  "error": "hook management requires master key",
  "error_detail": {
    "code": "AUTH_MASTER_KEY_REQUIRED",
    "message": "hook management requires master key"
  }
}
```
</ResponseExample>
