---
title: "Recover queued transactions"
sidebarTitle: "Queue recovery"
description: "Re-enqueue transactions that stayed queued."
method: "POST"
path: "/transactions/recover"
noindex: true
---
<Key />

### Query

<ParamField query="threshold" type="string">
  Minimum age of transactions to recover. Use duration format (e.g. `5m`, `10m`, `1h`). Default: `2m`. Minimum: 2 minutes.
</ParamField>

### Response

<ResponseField name="recovered" type="integer">
  Number of transactions re-enqueued for processing.
</ResponseField>

<ResponseField name="threshold" type="string">
  The threshold duration that was used (e.g. `2m0s`).
</ResponseField>

<RequestExample>
```bash cURL
curl -X POST "http://localhost:5001/transactions/recover?threshold=5m" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>

<ResponseExample>
```json 200 OK
{
  "recovered": 3,
  "threshold": "5m0s"
}
```

</ResponseExample>
