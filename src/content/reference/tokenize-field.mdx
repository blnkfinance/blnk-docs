description: "Replace one identity field with a token."

noindex: true
---

<Key />

<Version>Available in version 0.8.8 and later.</Version>

### Path

<ParamField path="identity_id" type="string" required>
  Id of the identity that holds the field.
</ParamField>

<ParamField path="field" type="string" required>
  PascalCase name of the field to tokenize: `FirstName`, `LastName`, `OtherNames`, `EmailAddress`, `PhoneNumber`, `Street`, or `PostCode`.
</ParamField>

### Response

<ResponseField name="message" type="string" required>
  Confirms the field is now a token.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "http://localhost:5001/identities/{identity_id}/tokenize/EmailAddress" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "message": "Field tokenized successfully"
}
```

```json 400 Bad Request
{
  "error": "field first_name is not tokenizable",
  "error_detail": {
    "code": "IDT_FIELD_NOT_TOKENIZABLE",
    "message": "field first_name is not tokenizable"
  }
}
```

```json 409 Conflict
{
  "error": "field EmailAddress is already tokenized",
  "error_detail": {
    "code": "IDT_FIELD_ALREADY_TOKENIZED",
    "message": "field EmailAddress is already tokenized"
  }
}
```

</ResponseExample>
