---
title: "Get ledger"
description: "See the details of one or all ledgers."
method: "GET"
path: "/ledgers/{ledger_id}"
noindex: true
---
<Key />

### Path

<ParamField path="ledger_id" type="string" required expanded>
  Unique `ledger_id` of the ledger being retrieved. Leave `ledger_id` out to return all ledgers.
</ParamField>

{/* <Tip>
When listing all ledgers, you can use [advanced filter operators](/search/db/filtering) to narrow down results by name, metadata, creation date, and more.
</Tip> */}

### Response

<Tabs>
  <Tab title="All ledgers">
    <ResponseField name="[]" type="array" expanded>
      <ResponseField name="ledger_id" type="string" required>
        Unique id to represent the ledger.
      </ResponseField>

      <ResponseField name="name" type="string" required>
        Name of the ledger.
      </ResponseField>

      <ResponseField name="created_at" type="string" required>
        Indicates the date & time of creation.
      </ResponseField>

      <ResponseField name="meta_data" type="User Object">
        Additional metadata of the ledger.
      </ResponseField>
    </ResponseField>
  </Tab>
  <Tab title="Single ledger">
    Returns one ledger.

    <ResponseField name="ledger_id" type="string" required>
      Unique id to represent the ledger.
    </ResponseField>

    <ResponseField name="name" type="string" required>
      Name of the ledger.
    </ResponseField>

    <ResponseField name="created_at" type="string" required>
      Indicates the date & time of creation.
    </ResponseField>

    <ResponseField name="meta_data" type="User Object">
      Additional metadata of the ledger.
    </ResponseField>
  </Tab>
</Tabs>

<RequestExample>

```bash View ledgers
curl -X GET "http://localhost:5001/ledgers" \
  -H "X-blnk-key: <api-key>"
```

```bash Get ledger
curl -X GET "http://localhost:5001/ledgers/{ledger_id}" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>
