---
title: "Update ledger name"
description: "Update the name of an existing ledger."
method: "PUT"
path: "/ledgers/{ledger_id}"
noindex: true
---
<Key />

### Path

<ParamField path="ledger_id" type="string" required>
  Unique `ledger_id` of the ledger whose name you want to update.
</ParamField>

### Body

<ParamField body="name" type="string" required>
  The new name for the ledger. Ensure it is descriptive and meaningful for easy reference.
</ParamField>

<RequestExample>

```bash cURL
curl -X PUT "http://localhost:5001/ledgers/{ledger_id}" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "Updated Customer Savings Ledger"
  }'
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "ledger_id": "ldg_073f7ffe-9dfd-42ce-aa50-d1dca1788adc",

```

</ResponseExample>
