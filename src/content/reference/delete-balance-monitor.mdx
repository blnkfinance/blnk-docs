<Key />

### Path

<ParamField path="monitor_id" type="string" required>
  The unique ID of the balance monitor to delete.
</ParamField>

<RequestExample>

```bash cURL
curl -X DELETE "http://localhost:5001/balance-monitors/{monitor_id}" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>

<ResponseExample>

```json 200 OK
{
  "message": "BalanceMonitor deleted successfully"
}
```

```json 404 Not Found
{
  "error": "Balance monitor not found",
  "error_detail": {
    "code": "BAL_MONITOR_NOT_FOUND",
    "message": "Balance monitor not found",
    "details": {}
  }
}
```

</ResponseExample>
