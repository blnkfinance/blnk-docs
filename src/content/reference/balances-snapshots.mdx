This call starts a snapshot of your balances. Blnk writes one snapshot per balance for the current day, using the amounts at the time of the call, and returns while that work continues. 

A later call the same day snapshots only balances that still have none for that day.

See [Balance snapshots](/balances/balance-snapshots) for when to run it and how historical balances use the stored snapshots.

<Key />

<RequestExample>

```bash cURL
curl -X POST "http://localhost:5001/balances-snapshots" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json"
```

</RequestExample>
