---
title: "Create role"
description: "Create a custom organization role."
method: "POST"
path: "/organizations/roles"
enterprise: license

---
Create a custom role for the current organization. The identifier cannot be a built-in role.

<Authorization />

### Body

<ParamField body="slug" type="string" required>
  Identifier for the role, such as `finance-ops`. Must not be `admin`, `member`, `operator`, `analyst`, or `investigator`.
</ParamField>

<ParamField body="name" type="string" required>
  Display name of the role.
</ParamField>

<ParamField body="description" type="string">
  What the role is for.
</ParamField>

<ParamField body="permissions" type="string[]" required>
  Permissions on the role. At least one. Each value must be from the [permission catalog](/access-control/rbac#permission-catalog).
</ParamField>

### Response

A `201` response returns the created role. Save `role_id`.

<ResponseField name="role_id" type="string" required>
  Id of the role (`role_...`). Use it to [update](/reference/update-role) or [delete](/reference/delete-role) the role.
</ResponseField>

<ResponseField name="slug" type="string" required>
  Identifier of the role. Use it when you [Assign role](/reference/assign-role).
</ResponseField>

<ResponseField name="name" type="string" required>
  Display name of the role.
</ResponseField>

<ResponseField name="description" type="string">
  What the role is for.
</ResponseField>

<ResponseField name="permissions" type="string[]" required>
  Permissions on the role.
</ResponseField>

<RequestExample>

```bash cURL
curl -X POST "https://api.cloud.blnkfinance.com/organizations/roles" \
  -H "X-blnk-key: CLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{
    "slug": "finance-ops",
    "name": "Finance Ops",
    "description": "Read billing and ledger data",
    "permissions": ["billing.read", "data.read", "instances.read", "org.read"]
  }'
```

</RequestExample>

<ResponseExample>

```json 201 Created
{
  "role_id": "role_8f2c1a40-6b1e-4d3a-9c70-1e5a2b4d8f16",
  "slug": "finance-ops",
  "name": "Finance Ops",
  "description": "Read billing and ledger data",
  "permissions": ["billing.read", "data.read", "instances.read", "org.read"]
}
```

</ResponseExample>
