Authenticate Enterprise API calls with an API key or with [OAuth](/reference/oauth). Create and manage keys in [Settings > API Keys](https://cloud.blnkfinance.com/cloud/settings/api-keys).

<Note>
An Enterprise API key is issued by the workspace. A [Core API key](/reference/core-api-key) is issued by the Core instance. Calling Core directly still uses the Core key.
</Note>

## How Enterprise API keys work

Send the key in the `X-blnk-key` header. 

On Blnk Cloud the host is `https://api.cloud.blnkfinance.com`. On a self-hosted Enterprise deployment the host is `ENTERPRISE_PUBLIC_URL`.

Each key has a name, a visible prefix such as `blnk_fdb796a5...`, scopes such as `*` or `mcp:read`, and an expiration. 

Expiration can be a date or **Never**.

## Create an API key

<Steps>
<Step title="Open API keys">
Go to [Settings > API Keys](https://cloud.blnkfinance.com/cloud/settings/api-keys). Click **Create API key**.

![API keys page with the Create API key button highlighted](img/cloud/api-keys-create-button.png)
</Step>
<Step title="Set the key">
- **Name:** Who or what will use the key, such as an alerts integration.
- **Type:** **API Key**.
- **Expiration:** When the key should stop working.
- **Scopes:** The permissions this key needs.

![Create API key panel with name, type, expiration, and scopes](img/cloud/api-keys-create-panel.png)
</Step>
<Step title="Copy the secret">
Click **Create API key**. The full key is shown once on **Save your API key**. Copy it before you click **Done**.

![Save your API key panel showing the full key and expiration details](img/cloud/api-keys-save.png)

<Warning>
The full key cannot be read again. If you lose it, revoke the key and create another.
</Warning>
</Step>
</Steps>

## Update expiration

Change when a key expires without creating a new secret.

<Steps>
<Step title="Open the key">
Click the key name in the API Keys table. In **Quick actions**, click **Update expiration**.

![API key details panel with Update expiration highlighted in Quick actions](img/cloud/api-key-expiration.png)
</Step>
<Step title="Set the new date">
Choose a new expiration and confirm. The secret stays the same. Only the expiration changes.

![Update API key expiration modal with expiration options](img/cloud/api-key-update-expiration-modal.png)
</Step>
</Steps>

## Revoke an API key

Revoke a key to stop it immediately. A revoked key stays in the list and cannot authenticate.

<Steps>
<Step title="Open the key">
Click the key name in the API Keys table.
</Step>
<Step title="Revoke it">
In the details panel, click **Revoke**.

<Warning>
Revoking a key disables it immediately. Apps using that key stop until you create a new one.
</Warning>
</Step>
<Step title="Confirm">
Confirm the revocation. The status in the table changes to **Revoked**.
</Step>
</Steps>
