---
title: "View identity details"
description: "See the details of one identity, or list every identity."
method: "GET"
path: "/identities/{identity_id}"
noindex: true
---
<Key />

### Path

<ParamField path="identity_id" type="string" required expanded>
  Id of the identity to retrieve. Leave `identity_id` out to return every identity, newest first.
</ParamField>

{/* <Tip>
When listing all identities, you can use [advanced filter operators](/search/db/filtering) to narrow down results by name, email, category, country, and more.
</Tip> */}

### Response

<Tabs>
  <Tab title="All identities">
    <ResponseField name="[]" type="array of identity objects">
      Each item is an identity and uses the same fields as a single identity.
    </ResponseField>
  </Tab>
  <Tab title="One identity">
    Returns one identity.

    <ResponseField name="identity_id" type="string" required>
      Id of the identity.
    </ResponseField>

    <ResponseField name="identity_type" type="string">
      `individual` or `organization`.
    </ResponseField>

    <ResponseField name="organization_name" type="string">
      Name of the organization.
    </ResponseField>

    <ResponseField name="first_name" type="string">
      First name of the individual.
    </ResponseField>

    <ResponseField name="last_name" type="string">
      Last name of the individual.
    </ResponseField>

    <ResponseField name="other_names" type="string">
      Other names linked to the individual.
    </ResponseField>

    <ResponseField name="gender" type="string">
      Gender of the individual.
    </ResponseField>

    <ResponseField name="dob" type="string">
      Date of birth.
    </ResponseField>

    <ResponseField name="email_address" type="string">
      Email address of the identity.
    </ResponseField>

    <ResponseField name="phone_number" type="string">
      Contact number of the identity.
    </ResponseField>

    <ResponseField name="nationality" type="string">
      Nationality of the individual.
    </ResponseField>

    <ResponseField name="category" type="string">
      Label stored for this customer.
    </ResponseField>

    <ResponseField name="street" type="string">
      Street address of the identity.
    </ResponseField>

    <ResponseField name="country" type="string">
      Country of the identity.
    </ResponseField>

    <ResponseField name="state" type="string">
      State or region of the identity.
    </ResponseField>

    <ResponseField name="post_code" type="string">
      Postal code of the identity.
    </ResponseField>

    <ResponseField name="city" type="string">
      City of the identity.
    </ResponseField>

    <ResponseField name="created_at" type="string" required>
      When Blnk created the identity.
    </ResponseField>

    <ResponseField name="meta_data" type="object">
      Custom metadata linked to the identity.
    </ResponseField>
  </Tab>
</Tabs>

<RequestExample>

```bash View identities
curl -X GET "http://localhost:5001/identities" \
  -H "X-blnk-key: <api-key>"
```

```bash Get identity
curl -X GET "http://localhost:5001/identities/{identity_id}" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>
