<Key />

### Path

<ParamField path="reconciliation_id" type="string" required>
  Id returned when you started the run. A missing id returns `400`. An unknown id returns `404` with `RECON_NOT_FOUND`.
</ParamField>

### Response

<ResponseField name="reconciliation_id" type="string" required>
  Id of the run.
</ResponseField>

<ResponseField name="upload_id" type="string" required>
  Upload this run is matching. An instant run uses a generated id.
</ResponseField>

<ResponseField name="status" type="string" required>
  `started`, `in_progress`, `completed`, or `failed`.
</ResponseField>

<ResponseField name="matched_transactions" type="integer" required>
  For `one_to_one`, external records that matched. For `one_to_many`, ledger transactions inside matched groups. For `many_to_one`, external rows inside matched groups.
</ResponseField>

<ResponseField name="unmatched_transactions" type="integer" required>
  For `one_to_one` and `one_to_many`, external records that did not match. For `many_to_one`, ledger transactions that did not match.
</ResponseField>

<ResponseField name="is_dry_run" type="boolean" required>
  Always `false`. Core does not store the dry-run flag.
</ResponseField>

<ResponseField name="started_at" type="string" required>
  When the run was created.
</ResponseField>

<ResponseField name="completed_at" type="string">
  When the run finished. Null until the status is `completed`.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "http://localhost:5001/reconciliation/recon_6e6feddd-930b-4e3a-8ba1-a3eee659bb3c" \
  -H "X-blnk-key: <api-key>"
```

</RequestExample>
