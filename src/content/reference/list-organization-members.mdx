List the people in the current organization.

Send `Authorization: Bearer` with a token for the current organization. On Blnk Cloud the host is `https://api.cloud.blnkfinance.com`. To invite someone or verify a domain, use the dashboard on [Team members](/access-control/team).

### Header

<ParamField header="Authorization" type="string" required>
  Bearer token for the current organization.
</ParamField>

### Response

The response is a JSON array. `user_id` is the id you pass when you [Assign role](/reference/assign-role). `status` is `pending` when the person has not finished joining, and `active` after they have.

<ResponseField name="user_id" type="string" required>
  Id of the member. Use this value as `{user_id}` on [Assign role](/reference/assign-role).
</ResponseField>

<ResponseField name="organization_id" type="string" required>
  Id of the current organization.
</ResponseField>

<ResponseField name="role" type="string" required>
  Role identifier, such as `admin` or `finance-ops`.
</ResponseField>

<ResponseField name="email" type="string" required>
  Email address of the member.
</ResponseField>

<ResponseField name="first_name" type="string" required>
  First name. `-` when `status` is `pending`.
</ResponseField>

<ResponseField name="last_name" type="string" required>
  Last name. `-` when `status` is `pending`.
</ResponseField>

<ResponseField name="status" type="string" required>
  `active` or `pending`.
</ResponseField>

<RequestExample>

```bash cURL
curl -X GET "https://api.cloud.blnkfinance.com/organizations/members" \
  -H "Authorization: Bearer YOUR_TOKEN"
```

</RequestExample>
