<Update label="1.8.4" description="Nov 19, 2026">
  ### Connect

  Connect to a Core URL you run, or to a managed Cloud instance with **`blnk connect --cloud --instance-id instance_…`**. Cloud connect uses your workspace API key and routes Core traffic through **`https://api.cloud.blnkfinance.com/proxy/...`**.

  Do not use the deployment URL with a workspace key from Cloud Settings. **`blnk info`** shows whether you are on a direct Core URL or Cloud proxy mode.

  ### Creates and updates

  Create a ledger, balance, identity, or transaction by passing flags. Leave the flags off and the CLI still asks. **`--json`** prints the Core response. **`--dry-run`** previews a transaction without writing it. **`--scheduled-for`** sets when a transaction should apply.

  ### Balances

  Read a balance as it stood at a past time, see where its funds came from, and start daily snapshots.

  ### Transactions

  Commit, void, or refund and print the response with `--json`. Submit many transfers from one file, and recover transfers that have been waiting in the queue.

  ### Reconciliation and metadata

  Upload external records, start a run, and fetch one run. Update the extra details stored on a ledger, balance, transaction, or identity.

  ### Docs and search

  **`blnk docs mcp`** prints how to add the Blnk Docs MCP to your agent. List commands use direct DB search only (no Typesense fallback). **`--json`** works on full list responses for ledgers, balances, transactions, identities, and reconciliations.

  ### Cloud API (preview)

  **`blnk cloud deployments create`** and **`edit`** call the Blnk Cloud API with flags (separate from Core **`connect --cloud`**).
</Update>

<Update label="1.8.2" description="Jul 10, 2026">
  ### Fixes & improvements

  Fixed field filters being ignored on list commands. Flags such as **`--status`**, **`--currency`**, and **`--balance-id`** now apply correctly across `ledgers`, `balances`, `transactions`, `identities`, and `reconciliations`.

  ```bash Filter by status wrap
  blnk transactions l --status APPLIED          # returns only APPLIED
  blnk transactions l --status "APPLIED,QUEUED" # matches either status
  ```
</Update>

<Update label="1.8.1" description="Jun 4, 2026">
  ### Connect

  Improved the flow for connecting your CLI to Blnk Core so you can start running commands against your instance.

  ### List & search

  List commands now default to direct DB search. On older Blnk Core versions without direct DB search, the CLI falls back to Typesense. You can also filter results by field across list commands.

  ### Fixes & improvements

  1. Added **`reindex`**, **`community`**, and **`docs`** to create and list search reindex jobs, open the Blnk community, or jump to the docs from your terminal.
  2. Expanded **`update`** flows with guided prompts, including identity ID handling for balance updates.
  3. Broader command coverage for ledgers, balances, transactions, identities, and reconciliations.
  4. Improved table output, help text, flags, and status coloring across commands.
  5. Stronger error handling for invalid arguments, API failures, and prompt flows.
  6. Removed legacy **cloud** CLI surface and unused dependencies.
  7. **Node.js 18+** is now required.
  8. Added field filtering to list and query flows. (A follow-up fix in **1.8.2** resolved filters not applying correctly.)
</Update>
