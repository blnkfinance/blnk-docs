Use `blnk.BalanceMonitor.updatePartial` to update selected monitor fields.

<Version>Requires SDK **1.7.0** and Core **0.15.9 or later**. Omitted fields stay unchanged. With older Core, use `update` and send the full monitor.</Version>

## Update selected fields

```typescript updatePartial
const response = await blnk.BalanceMonitor.updatePartial(
  'mon_e0e77b0c-4985-472a-9bf5-76a48b0259b0',
  {condition: {value: 50}},
);
console.log(response.data);
```

<Steps>
<Step title="Call the method">

```typescript blnk.BalanceMonitor.update
const response = await blnk.BalanceMonitor.update(
  'mon_e0e77b0c-4985-472a-9bf5-76a48b0259b0',
  {
    balance_id: 'bln_5ce86029-3c2e-4e2a-aae2-7fb931ca4c4f',
    condition: {
      field: 'credit_balance',
      operator: '<',
      value: 500,
      precision: 100,
    },
    call_back_url: 'https://api.example.com/balance-monitor',
  },
);
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `string` | Monitor ID to update. |
| `balance_id` | `string` | Balance to monitor. |
| `condition` | `object` | Threshold rule with `field`, `operator`, `value`, and `precision`. |
| `condition.field` | `string` | Balance field to watch (for example `credit_balance`, `debit_balance`, `balance`). |
| `condition.operator` | `string` | Comparison operator: `>`, `<`, `=`, `!=`, `>=`, `<=`. |
| `condition.value` | `number` | Threshold amount. |
| `condition.precision` | `number` | Currency precision (for example `100` for cents). |
| `call_back_url` | `string` | Webhook URL when the condition is met. |
| `description` | `string` | Optional description for the monitor. |
</Step>

<Step title="Confirm the update">

On success, Core returns a confirmation message. Fetch the monitor with [get balance monitor](/sdks/typescript/ledger-balances/get-balance-monitor) to verify the new condition and webhook URL.

</Step>

<Step title="Response">

```json 200 OK
{
  "message": "BalanceMonitor updated successfully"
}
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `message` | `string` | Confirmation from Core. |
</Step>
</Steps>
