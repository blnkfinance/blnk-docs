Use `blnk.BalanceMonitor.list` to retrieve all balance monitors.

<Steps>
<Step title="Call the method">

<RequestExample>

```typescript blnk.BalanceMonitor.list
const response = await blnk.BalanceMonitor.list();
```

</RequestExample>

This method takes no arguments.
</Step>

<Step title="Use the monitor list">

Iterate over `response.data` to find monitors by `balance_id` or `monitor_id`. Save IDs you need for updates or lookups.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
[
  {
    "monitor_id": "mon_e0e77b0c-4985-472a-9bf5-76a48b0259b0",
    "balance_id": "bln_5ce86029-3c2e-4e2a-aae2-7fb931ca4c4f",
    "condition": {
      "field": "credit_balance",
      "operator": ">",
      "value": 1000,
      "precision": 100
    },
    "call_back_url": "https://api.example.com/balance-monitor",
    "description": "Low balance alert",
    "created_at": "2024-02-20T05:56:58.257315054Z"
  }
]
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `response.data` | `object[]` | Array of balance monitor objects. |
</Step>
</Steps>
