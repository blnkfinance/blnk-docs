---
title: "Get reconciliation"
sidebarTitle: "Get reconciliation"
description: "Get reconciliation status and match counts with the Java SDK."
method: "GET"
path: "/reconciliation/{reconciliation_id}"
---

Use `blnk.reconciliation().get` for this operation.

<Steps>
<Step title="Call the method">

<RequestExample>

```java reconciliation().get
ApiResponse<JsonNode> response = blnk.reconciliation().get(
    "recon_073f7ffe-9dfd-42ce-aa50-d1dca1788adc"
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `reconciliationId` | `String` | ID of the reconciliation run to retrieve. |
</Step>

<Step title="Use the reconciliation details">

Read `response.data()` for status, matched and unmatched counts, and creation time. Poll this endpoint after starting a batch or instant run until status is `completed`.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "reconciliation_id": "rec-123",
  "status": "completed",
  "matched_transactions": 20,
  "unmatched_transactions": 5,
  "created_at": "2025-03-17T12:00:00Z"
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `reconciliation_id` | `String` | ID of the reconciliation run. |
| `status` | `String` | Current status of the run, for example `completed`. |
| `matched_transactions` | `Number` | Number of records that matched. |
| `unmatched_transactions` | `Number` | Number of records that did not match. |
| `created_at` | `String` | When the reconciliation started. |
</Step>
</Steps>
