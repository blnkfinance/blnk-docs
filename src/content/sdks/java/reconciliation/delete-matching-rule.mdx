---
title: "Delete matching rule"
sidebarTitle: "Delete matching rule"
description: "Delete a reconciliation matching rule with the Java SDK."
method: "DELETE"
path: "/reconciliation/matching-rules/{rule_id}"
---

Use `blnk.reconciliation().deleteMatchingRule` for this operation.

<Steps>
<Step title="Call the method">

<RequestExample>

```java reconciliation().deleteMatchingRule
ApiResponse<JsonNode> response = blnk.reconciliation().deleteMatchingRule(
    "rule_073f7ffe-9dfd-42ce-aa50-d1dca1788adc"
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `ruleId` | `String` | ID of the matching rule to delete. |
</Step>

<Step title="Confirm the outcome">

Check the response message to confirm the rule was removed. Reconciliation runs that reference this rule ID will no longer apply it.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "message": "Matching rule deleted successfully"
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `message` | `String` | Confirmation that the rule was deleted. |
</Step>
</Steps>
