---
title: "Get transaction by reference"
sidebarTitle: "Get transaction by reference"
description: "Retrieve a transaction by its reference with the Java SDK."
method: "GET"
path: "/transactions/reference/{reference}"
---

Use `blnk.transactions().getByReference` for this operation.

<Steps>
<Step title="Call the method">

<RequestExample>

```java transactions().getByReference
ApiResponse<JsonNode> response = blnk.transactions().getByReference(
    "ref_f482a1b3-6c2d-4e89-a17b-3d5e8f2a1c94"
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `reference` | `String` | Unique reference passed when the transaction was created. |
</Step>

<Step title="Use the transaction details">

Use the returned transaction ID when you need to refund, update inflight status, or inspect lineage.

</Step>
