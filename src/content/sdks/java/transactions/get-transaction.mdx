---
title: "Get transaction"
sidebarTitle: "Get transaction"
description: "Retrieve a transaction by its ID with the Java SDK."
method: "GET"
path: "/transactions/{transaction_id}"
---

Use `blnk.transactions().get` for this operation.

<Note>
The Java SDK does not expose a list method for transactions. Use [Search](/sdks/java/search/search-db) or get by reference instead.
</Note>

<Steps>
<Step title="Call the method">

<RequestExample>

```java transactions().get
ApiResponse<JsonNode> response = blnk.transactions().get(
    "txn_f482a1b3-6c2d-4e89-a17b-3d5e8f2a1c94"
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `transactionId` | `String` | Transaction ID to retrieve. |
</Step>

<Step title="Use the transaction details">

Read `response.data()` for status, amounts, source, destination, and metadata. Use the transaction ID for refunds, inflight updates, or lineage queries.

</Step>

| Field | Type | Description |
| :-- | :-- | :-- |
| `transaction_id` | `String` | Unique ID for the transaction. |
| `status` | `String` | Current [status](/transactions/transaction-lifecycle#statuses) of the transaction. |
