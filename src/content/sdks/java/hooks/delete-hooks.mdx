---
title: "Delete hook"
sidebarTitle: "Delete hook"
description: "Delete a hook with the Java SDK."
method: "DELETE"
path: "/hooks/{hook_id}"
---

Use `blnk.hooks().delete` for this operation.

<Steps>
<Step title="Call the method">

```java hooks().delete
ApiResponse<JsonNode> response = blnk.hooks().delete(
    "hk_890bdbc4-467f-4670-8424-5667e41daf29"
);
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `String` | ID of the hook to delete. |
</Step>

<Step title="Confirm the outcome">

Check the response message to confirm the hook was removed. Blnk will no longer call this endpoint on transactions.

</Step>

<Step title="Response">

```json 200 OK
{
  "message": "hook deleted successfully"
}
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `message` | `String` | Confirmation that the hook was deleted. |
</Step>
</Steps>
