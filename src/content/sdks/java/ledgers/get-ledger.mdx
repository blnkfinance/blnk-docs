---
title: "Get ledger"
sidebarTitle: "Get ledger"
description: "Get a ledger by ID with the Java SDK."
method: "GET"
path: "/ledgers/{ledger_id}"
---

Use `blnk.ledgers().get` for this operation.

<Steps>
<Step title="Call the method">

<RequestExample>

```java ledgers().get
ApiResponse<JsonNode> response = blnk.ledgers().get(
    "ldg_073f7ffe-9dfd-42ce-aa50-d1dca1788adc"
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `String` | Ledger ID to retrieve. |
</Step>

<Step title="Use the ledger details">

Read `response.data()` for the ledger name, metadata, and creation time. Use these values to confirm you have the correct ledger before creating balances or transactions.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "ledger_id": "ldg_049495c6-356e-4ebc-a45e-60d1e1e16afb",
  "name": "Customer Checking Ledger",
  "created_at": "2024-11-26T08:23:57.509804Z",
  "meta_data": {
    "project_owner": "Blnk Tech"
  }
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `ledger_id` | `String` | Unique ID for the ledger. |
| `name` | `String` | Current display name. |
| `created_at` | `String` | Date and time the ledger was created. |
| `meta_data` | `JsonNode` | Metadata object, if one was set at creation. |
</Step>
</Steps>
