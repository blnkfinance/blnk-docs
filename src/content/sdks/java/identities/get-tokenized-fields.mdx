---
title: "Get tokenized fields"
sidebarTitle: "Get tokenized fields"
description: "See which identity fields are tokenized with the Java SDK."
method: "GET"
path: "/identities/{identity_id}/tokenized-fields"
---

Use `blnk.identity().getTokenizedFields` for this operation.

<Steps>
<Step title="Call the method">

<RequestExample>

```java identity().getTokenizedFields
ApiResponse<JsonNode> response = blnk.identity().getTokenizedFields(
    "idt_073f7ffe-9dfd-42ce-aa50-d1dca1788adc"
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `String` | Identity ID. |
</Step>

<Step title="Use the field list">

Read `response.data().get("tokenized_fields")` to see which profile fields are protected. Use this before detokenizing specific fields.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "tokenized_fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"]
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `tokenized_fields` | `List<String>` | Field names currently tokenized on the identity. |
</Step>
</Steps>
