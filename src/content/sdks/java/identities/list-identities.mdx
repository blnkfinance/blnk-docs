Use `blnk.identity().list` for this operation.

<Steps>
<Step title="Call the method">

```java identity().list
ApiResponse<JsonNode> response = blnk.identity().list();
```

This method takes no arguments.
</Step>

<Step title="Use the identity list">

When `response.data().isArray()`, iterate by index:

```java Use the identity list wrap
JsonNode identities = response.data();
for (int i = 0; i < identities.size(); i++) {
  String identityId = identities.get(i).get("identity_id").asText();
}
```

Save identity IDs you need for balance linking or profile updates.

</Step>

<Step title="Response">

```json 200 OK
[
  {
    "identity_id": "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
    "identity_type": "individual",
    "first_name": "Alice",
    "last_name": "Smith",
    "email_address": "alice.smith@example.com",
    "created_at": "2024-11-26T08:36:36.238244338Z"
  }
]
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `response.data()` | `JsonNode` | JSON array of identity objects returned by Core. |
| `response.data().`<br />`get(i).get("identity_id")` | `String` | Unique identity ID. |
</Step>
</Steps>
