---
title: "Delete identity"
sidebarTitle: "Delete identity"
description: "Delete an identity with the Java SDK."
method: "DELETE"
path: "/identities/{identity_id}"
---

Use `blnk.identity().delete` for this operation.

<Steps>
<Step title="Call the method">

<RequestExample>

```java identity().delete
ApiResponse<JsonNode> response = blnk.identity().delete(
    "idt_073f7ffe-9dfd-42ce-aa50-d1dca1788adc"
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `String` | Identity ID to delete. |
</Step>

<Step title="Confirm the outcome">

Check the response message to confirm the identity was removed. Blnk will no longer return this identity on subsequent requests.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "message": "Identity deleted successfully"
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `message` | `String` | Confirmation that the identity was deleted. |
</Step>
</Steps>
