Use `blnk.search().startReindex` for this operation.

<Steps>
<Step title="Call the method">

<RequestExample>

```java search().startReindex
ApiResponse<JsonNode> response = blnk.search().startReindex(
    StartReindexRequest.create().batchSize(500)
);
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `batch_size` | `Number` | Records processed per batch. Omit the argument to use the Core default. Must be a positive integer when set. |
</Step>

<Step title="Poll reindex progress">

Use [get reindex status](/sdks/java/search/get-reindex) to track progress until `status` is `completed`.

</Step>

<Step title="Response">

<ResponseExample>

```json 202 Accepted
{
  "message": "Reindex operation started",
  "progress": {
    "status": "in_progress",
    "phase": "indexing_transactions",
    "total_records": 2145709,
    "processed_records": 0,
    "started_at": "2026-02-12T12:13:10.448612096Z"
  }
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `message` | `String` | Confirmation that the reindex job started. |
| `progress` | `JsonNode` | Initial progress snapshot with `status`, `phase`, `total_records`, `processed_records`, and `started_at`. |
</Step>
</Steps>
