method: "GET"
path: "/identities/{identity_id}/tokenized-fields"
---

Use `blnk.identity.get_tokenized_fields` to list tokenized identity fields.

<Steps>
<Step title="Call the method">

<RequestExample>

```python blnk.identity.get_tokenized_fields
response = blnk.identity.get_tokenized_fields(
  "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
)
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `str` | Identity ID. |
</Step>

<Step title="Use the field list">

Read `response.data["tokenized_fields"]` to see which profile fields are protected. Use this before detokenizing specific fields.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "tokenized_fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"]
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `tokenized_fields` | `string[]` | Field names currently tokenized on the identity. |
</Step>
</Steps>
