Use `blnk.balance_monitor.delete` to remove a [balance monitor](/balances/balance-monitoring) by its ID.

<Steps>
<Step title="Call the method">

<RequestExample>

```python blnk.balance_monitor.delete
response = blnk.balance_monitor.delete("mon_e0e77b0c-4985-472a-9bf5-76a48b0259b0")
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `str` | Monitor ID to delete. |
</Step>

<Step title="Confirm the outcome">

Check the response message to confirm the monitor was removed. Blnk will no longer check thresholds or send webhooks for that monitor.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "message": "BalanceMonitor deleted successfully"
}
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `message` | `str` | Confirmation that the monitor was deleted. |
</Step>
</Steps>
