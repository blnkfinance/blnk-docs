Use `blnk.api_keys.list` to list [API keys](/advanced/secure-blnk) for an owner.

<Steps>
<Step title="Call the method">

<RequestExample>

```python blnk.api_keys.list
response = blnk.api_keys.list({
  "owner": "merchant_a",
})
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `owner` | `str` | Owner whose keys to return. Required when authenticating with the master key. |
</Step>

<Step title="Use the key list">

Iterate over `response.data` to find keys by name, scopes, or expiration. Plaintext key values are not included in list results.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
[
  {
    "api_key_id": "key_abc123def456",
    "name": "Service Account",
    "owner_id": "owner_id",
    "scopes": ["ledgers:read", "balances:write"],
    "expires_at": "2026-03-11T00:00:00Z",
    "created_at": "2024-01-15T10:30:00Z",
    "last_used_at": "2024-01-20T14:30:00Z"
  }
]
```

</ResponseExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `response.data` | `list[dict]` | Array of API key records without the plaintext key value. |
</Step>
</Steps>
