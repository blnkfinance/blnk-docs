Use `client.Ledger.Create` to create a new [ledger](/ledgers/general-ledger) for your system.

<Steps>
<Step title="Call the method">

```go client.Ledger.Create
ledger, resp, err := client.Ledger.Create(blnkgo.CreateLedgerRequest{
	Name: "Customer wallets",
	MetaData: blnkgo.MetaData{
		"environment": "production",
	},
})
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `Name` | `string` | Display name for the ledger. |
| `MetaData` | `MetaData` | Optional key-value metadata. |
</Step>

<Step title="Response">

```json 201 Created
{
  "ledger_id": "ldg_073f7ffe-9dfd-42ce-aa50-d1dca1788adc",
  "name": "Customer wallets",
  "created_at": "2024-02-20T05:28:03.558281542Z",
  "meta_data": {
    "environment": "production"
  }
}
```

#### Go response (`*blnkgo.Ledger`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `LedgerID` | `string` | Unique ID for the ledger. |
| `Name` | `string` | Name you passed in the request. |
| `CreatedAt` | `time.Time` | Date and time the ledger was created. |
| `MetaData` | `MetaData` | Metadata object, if you sent one. |
</Step>
</Steps>
