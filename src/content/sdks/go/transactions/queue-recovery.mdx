Use `client.Transaction.RecoverQueue` to retry queued transactions.

<Steps>
<Step title="Call the method">

```go client.Transaction.RecoverQueue
result, _, _ := client.Transaction.RecoverQueue(blnkgo.RecoverQueueRequest{
	Threshold: "5m",
})
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `Threshold` | `string` | Minimum age of transactions to recover (for example `5m`, `1h`). Default `2m`. Minimum 2 minutes. |
</Step>

<Step title="Response">

```json 200 OK
{
  "recovered": 3,
  "threshold": "5m0s"
}
```

#### Go response (`*blnkgo.RecoverQueueResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `Recovered` | `int` | Number of transactions re-enqueued for processing. |
| `Threshold` | `string` | Threshold duration that was used. |
</Step>
</Steps>
