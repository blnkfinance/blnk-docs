Use `client.Health.Check` to check whether Core is reachable.

<Steps>
<Step title="Call the method">

<RequestExample>

```go client.Health.Check
health, resp, err := client.Health.Check()
```

</RequestExample>

This method takes no arguments.
</Step>

<Step title="Confirm Core is healthy">

Check that `health.Status` is `UP` before running other SDK calls in health checks or startup probes.

</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "status": "UP"
}
```

</ResponseExample>

#### Go response (`*blnkgo.HealthResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `Status` | `string` | `UP` when Core is healthy and reachable. |
| `Reason` | `string` | Optional detail when Core reports an unhealthy state. |
</Step>
</Steps>
