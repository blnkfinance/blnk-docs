path: "/balances/{balance_id}/identity"
---

Use `client.LedgerBalance.UpdateIdentity` to link a balance to an [identity](/identities/link-balances).

<Steps>
<Step title="Call the method">

<RequestExample>

```go client.LedgerBalance.UpdateIdentity
result, resp, err := client.LedgerBalance.UpdateIdentity(
	"bln_5ce86029-3c2e-4e2a-aae2-7fb931ca4c4f",
	blnkgo.UpdateBalanceIdentityRequest{
		IdentityID: "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
	},
)
```

</RequestExample>

| Field | Type | Description |
| :-- | :-- | :-- |
| `balanceID` | `string` | Balance ID to update. |
| `IdentityID` | `string` | Identity ID to link to the balance. |
</Step>

<Step title="Response">

<ResponseExample>

```json 200 OK
{
  "message": "Balance identity updated successfully"
}
```

</ResponseExample>

#### Go response (`*blnkgo.UpdateBalanceIdentityResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `Message` | `string` | Confirmation from Core. |
</Step>
</Steps>
