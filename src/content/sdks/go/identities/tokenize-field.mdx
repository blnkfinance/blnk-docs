---
title: "Tokenize field"
sidebarTitle: "Tokenize field"
description: "Tokenize a single identity field with the Go SDK."
method: "POST"
path: "/identities/{identity_id}/tokenize/{field}"
---

Use `client.Identity.TokenizeField` to tokenize one identity field.

<Steps>
<Step title="Call the method">

```go client.Identity.TokenizeField
tokenized, _, _ := client.Identity.TokenizeField(
	"idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
	string(blnkgo.TokenizableFieldEmailAddress),
)
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `identityID` | `string` | Identity ID. |
| `field` | `string` | PascalCase field name to tokenize. |
</Step>

<Step title="Confirm tokenization">

Check `tokenized.Message`, then use [get tokenized fields](/sdks/go/identities/get-tokenized-fields) to verify the field is protected.

</Step>

<Step title="Response">

```json 201 Created
{
  "message": "Field tokenized successfully"
}
```

#### Go response (`*blnkgo.TokenizeFieldResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `Message` | `string` | Confirmation that the field was tokenized. |
</Step>
</Steps>
