---
title: "Get tokenized fields"
sidebarTitle: "Get tokenized fields"
description: "See which identity fields are tokenized with the Go SDK."
method: "GET"
path: "/identities/{identity_id}/tokenized-fields"
---

Use `client.Identity.GetTokenizedFields` to list tokenized identity fields.

<Steps>
<Step title="Call the method">

```go client.Identity.GetTokenizedFields
fields, _, _ := client.Identity.GetTokenizedFields(
	"idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
)
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `identityID` | `string` | Identity ID. |
</Step>

<Step title="Use the field list">

Read `fields.TokenizedFields` to see which profile fields are protected. Use this before detokenizing specific fields.

</Step>

<Step title="Response">

```json 200 OK
{
  "tokenized_fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"]
}
```

#### Go response (`*blnkgo.GetTokenizedFieldsResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `TokenizedFields` | `[]TokenizableIdentityField` | Field names currently tokenized on the identity. |
</Step>
</Steps>
