---

Use `client.Identity.Tokenize` to tokenize several identity fields.

<Steps>
<Step title="Call the method">

```go client.Identity.Tokenize
tokenized, _, _ := client.Identity.Tokenize(
	"idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
	blnkgo.TokenizeRequest{
		Fields: []blnkgo.TokenizableIdentityField{
			blnkgo.TokenizableFieldFirstName,
			blnkgo.TokenizableFieldEmailAddress,
		},
	},
)
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `identityID` | `string` | Identity ID. |
| `Fields` | `[]TokenizableIdentityField` | PascalCase field names to tokenize. At least one required. |
</Step>

<Step title="Confirm tokenization">

Check `tokenized.Message`, then use [get tokenized fields](/sdks/go/identities/get-tokenized-fields) to verify which fields are protected.

</Step>

<Step title="Response">

```json 201 Created
{
  "message": "Fields tokenized successfully"
}
```

#### Go response (`*blnkgo.TokenizeResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `Message` | `string` | Confirmation that the fields were tokenized. |
</Step>
</Steps>
