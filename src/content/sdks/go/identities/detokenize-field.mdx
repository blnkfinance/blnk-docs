---
title: "Detokenize field"
sidebarTitle: "Detokenize field"
description: "Detokenize a single identity field with the Go SDK."
method: "GET"
path: "/identities/{identity_id}/detokenize/{field}"
---

Use `client.Identity.DetokenizeField` to detokenize one identity field. This call is a GET.

<Steps>
<Step title="Call the method">

```go client.Identity.DetokenizeField
field, _, _ := client.Identity.DetokenizeField(
	"idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
	string(blnkgo.TokenizableFieldEmailAddress),
)
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `identityID` | `string` | Identity ID. |
| `field` | `string` | PascalCase field name to detokenize. |
</Step>

<Step title="Use the plaintext value">

Read `field.Value` for the original field value. Handle it securely and avoid logging it.

</Step>

<Step title="Response">

```json 200 OK
{
  "field": "EmailAddress",
  "value": "alice.smith@example.com"
}
```

#### Go response (`*blnkgo.DetokenizeFieldResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `Field` | `string` | Field you detokenized. |
| `Value` | `string` | Original plaintext value. |
</Step>
</Steps>
