method: "POST"
path: "/identities/{identity_id}/detokenize"
---

Use `client.Identity.Detokenize` to detokenize several identity fields.

<Steps>
<Step title="Call the method">

```go client.Identity.Detokenize
values, resp, err := client.Identity.Detokenize(
	"idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
	blnkgo.DetokenizeRequest{
		Fields: []blnkgo.TokenizableIdentityField{
			blnkgo.TokenizableFieldFirstName,
			blnkgo.TokenizableFieldEmailAddress,
		},
	},
)
```

| Field | Type | Description |
| :-- | :-- | :-- |
| `identityID` | `string` | Identity ID. |
| `Fields` | `[]TokenizableIdentityField` | PascalCase field names to detokenize. Pass an empty slice to detokenize every tokenized field. |
</Step>

<Step title="Use the plaintext values">

Read `values.Fields` for the original values. Handle these values securely and avoid logging them.

</Step>

<Step title="Response">

```json 200 OK
{
  "fields": {
    "FirstName": "Jane",
    "EmailAddress": "jane@example.com"
  }
}
```

#### Go response (`*blnkgo.DetokenizeResponse`)

| Field | Type | Description |
| :-- | :-- | :-- |
| `Fields` | `map[string]string` | Original values for the fields you requested. |
</Step>
</Steps>
