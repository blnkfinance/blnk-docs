Search is how you read ledgers, balances, transactions, and identities already stored in Blnk. 

There are two main ways to retrieve data from Blnk: Filter API and Data Lake.

## Filter API

The [Filter API](/search/db/filtering) is the main way to search and retrieve data from the ledger. 

It retrieves ledgers, balances, transactions, and identities, and you compose the filters for the records you need.

<Tip>If required, Blnk also supports [Typesense](/search/typesense/introduction) for advanced search functionality. </Tip>

## Data Lake

The [data lake](/lake/overview) is for custom SQL and large queries over ledger history. Insights and the Data Lake API run that work on a reporting copy, which keeps it off the database processing transactions.

Choose it for a period report, an investigation, or a question you write in SQL. It is available on managed instances and with an Enterprise license.
