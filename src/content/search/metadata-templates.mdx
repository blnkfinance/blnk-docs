Metadata adds extra context to your records, such as customer type, product line, region, provider, reference IDs, approval status, or internal tags. When teams type those fields by hand, the same key gets written inconsistently, and re-entering it for every record gets slow. A metadata template is a reusable set of keys you define once and import whenever you add or edit metadata.

## When to use metadata templates

Use a template when similar records should share the same keys.

- A loan app can reuse loan ID, repayment schedule, risk tier, and loan officer.
- A wallet product can reuse customer segment, wallet type, provider, and region.
- A treasury team can reuse account type, bank partner, settlement cycle, and currency corridor.

Shared keys make the data easier to filter, compare, and review across the workspace.

## Create a metadata template

<Tabs>
  <Tab title="Using the API">

Call [Create metadata template](/reference/create-metadata-template) with a `name` and the `keys` to add. `description` is optional.

<CodeGroup>
```bash cURL
curl -X POST 'https://api.cloud.blnkfinance.com/data/metadata-templates' \
  -H 'X-blnk-key: CLOUD_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "Loan metadata",
    "description": "Fields for every loan balance and disbursement",
    "keys": [
      "loan_id",
      "risk_tier",
      "repayment_schedule",
      "loan_officer"
    ]
  }'
```

```json 201 Created
{
  "metadata_template_id": "metadata_template_7c1e9a42-5b3d-4f8e-9a61-2d4c8b0e3f57",
  "name": "Loan metadata",
  "description": "Fields for every loan balance and disbursement",
  "keys": [
    "loan_id",
    "risk_tier",
    "repayment_schedule",
    "loan_officer"
  ],
  "org_id": "org_01K4EX0BRXHNNGCRVT2TPNK07W",
  "created_at": "2026-11-11T09:14:22.418203Z",
  "updated_at": "2026-11-11T09:14:22.418203Z"
}
```
</CodeGroup>

Template names must be unique in your organization. Blnk trims each key, drops empty ones, and removes duplicates without regard to case. Save `metadata_template_id` to update or delete the template later.

  </Tab>
  <Tab title="Using the Dashboard">

<Steps>
<Step title="Open Metadata templates">

Go to [Settings > Metadata templates](https://cloud.blnkfinance.com/cloud/settings/metadata-templates).

</Step>
<Step title="Add the template">

Click **Create template**.

- **Name:** a clear name, such as `Loan metadata`, `Customer wallet`, or `Provider settlement`
- **Description:** a short note explaining when the template should be used
- **Keys:** the metadata keys to add. You can add more than one key.

![Metadata templates settings page](img/organization/metadata-templates-page.png)

</Step>
</Steps>

  </Tab>
</Tabs>

You can edit or delete a template after it is created. In the Dashboard, open the **Actions** menu on the template row and select **Edit** or **Delete**. With the API, call [Update metadata template](/reference/update-metadata-template) or [Delete metadata template](/reference/delete-metadata-template). [List metadata templates](/reference/list-metadata-templates) returns every template in your organization.

## Use a metadata template

You can use a template on any form that has a metadata section.

<Steps>
<Step title="Choose a template">

Click **Use template**, then search by template name or key and select the one you want.

</Step>
<Step title="Fill in the values">

The template keys are added to the form. Fill in the values for that record.

To add another template, click **Use template** again. You can also add a key by hand when that record needs something the template does not include.

![Use template dropdown on the create ledger form](img/organization/metadata-use-template-ledger.png)

</Step>
</Steps>
