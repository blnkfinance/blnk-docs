### Enterprise authentication

Send these requests to `https://api.cloud.blnkfinance.com` on Blnk Cloud. On a self-hosted Enterprise deployment, send them to `ENTERPRISE_PUBLIC_URL`.

Pass a Cloud or Enterprise API key, or an OAuth access token, in the `X-blnk-key` header. Create the key in [API keys](/reference/api-keys), or issue a token with [OAuth](/reference/oauth).

This credential comes from the Cloud or Enterprise workspace. A Core API key belongs to the Core instance and is documented on the Core reference pages.

<ParamField header="X-blnk-key" type="string" required>
	Cloud or Enterprise API key, or an OAuth access token.
</ParamField>
