### Enterprise authentication

Send these requests to `https://api.cloud.blnkfinance.com` on Blnk Cloud. On a self-hosted Enterprise deployment, send them to `ENTERPRISE_PUBLIC_URL`.

Pass an Enterprise API key, or an OAuth access token, in the `X-blnk-key` header. Create the key in [Enterprise API keys](/reference/enterprise-api-key), or issue a token with [OAuth](/access-control/oauth).

This credential comes from the Cloud or Enterprise workspace. A [Core API key](/reference/core-api-key) belongs to the Core instance.

<ParamField header="X-blnk-key" type="string" required>
	Enterprise API key, or an OAuth access token.
</ParamField>
