Install an app from the Apps library. The install is available in the organization and Core instance you selected.

An app can be installed on one Core instance and unavailable on another. Before you start, confirm you are in the right organization and have selected the Core instance where you want the app.

The Apps library includes two types of apps:

- **Official apps:** Built and managed by Blnk.
- **Private apps:** Built and managed by your organization.

<Info>
For a runnable Stripe Sync example you can clone and register, use the [blnkfinance/apps-demo](https://github.com/blnkfinance/apps-demo) repository on GitHub.
</Info>

## Prerequisites

A Core instance that Blnk hosts is ready to install apps. For a Core you connect yourself, set the **Core URL** and **Core secret key** on the instance, and make sure that URL is reachable.

On Blnk Cloud, connect it from [Open-source Core](/deploy/open-source#connect-to-the-dashboard). If Core is on a private network, allow the Cloud IPs on that page. On Enterprise, connect it from [Enterprise Core](/deploy/enterprise).

## Install an app

To install an app:

<Steps>
  <Step title="Open Apps library">
    Open **Apps** at the bottom of the sidebar.

    <Note>
      Confirm you are on the Core instance where you want the app. The active instance is in the top right of the screen.
    </Note>
  </Step>
  <Step title="Choose an app">
    Open the app and review what it does, the permissions it requires, and any other details you need. When it is the app you want, click **Install**.
  </Step>
  <Step title="Review permissions">
    Review what the app is allowed to access or do inside your ledger.

    1. Review the requested permissions.
    2. Select the permissions you want to grant.
    3. Click **Continue**.

    ![Permissions an app requests before install](img/apps/install-apps-review-access.png)

    This keeps the app limited to what you grant.
  </Step>
  <Step title="Confirm installation">
    Enter your account password and 2FA code when 2FA is on.

    This step blocks an install from an unauthorized session.
  </Step>
</Steps>

<Tip>
Launch the app from its details page with **Launch app** in the top right. Launch is usually one click. Some apps ask for your password and 2FA again before they open.
</Tip>

## Pin an app for your team

Pinning applies to the whole organization. Everyone in the workspace sees the same pinned apps in the sidebar.

Pin from the **Apps** list. You do not need to open the app details.

<Steps>
  <Step title="Open Apps">
    Open **Apps** from the bottom of the sidebar.
  </Step>
  <Step title="Pin for the team">
    On the installed app card, click the pin icon. The tooltip is **Pin to sidebar for your team**.
  </Step>
</Steps>

Blnk confirms with a toast. Pinned apps sort to the top of the library and show in the sidebar for your team.

To take it off the sidebar for everyone, click the pin again. The tooltip is **Unpin from sidebar for your team**.

## Uninstall an app

To uninstall an app:

<Steps>
  <Step title="Open the app details">
    From **Apps**, open the app you want to uninstall.

    Confirm you are viewing the organization and Core instance where the app is installed.
  </Step>
  <Step title="Uninstall the app">
    Click **Uninstall** on the app details page. If your app doesn't respond to an uninstall event, Blnk revokes the key nonetheless and uninstalls the app.
  </Step>
</Steps>

## Troubleshooting

If something goes wrong during installation, try one of these:

| Issue | What to do |
| :--- | :--- |
| Permissions do not load | Reopen the install flow and try again. |
| Password or 2FA is incorrect | Check your password or 2FA code and try again. You may see `Authentication failed`. |
| Install fails | Return to the app details page and click **Install** again. |
| App is not visible after install | Confirm you are viewing the same organization and Core instance where the app was installed. |
| Private app not loading | Check that your app is live and Blnk can reach it. |
