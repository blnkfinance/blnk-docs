<Version>Available in version 0.8.8 and later.</Version>

PII tokenization replaces a sensitive identity field with a token. Blnk keeps the token on the identity, and returns the original value only when you detokenize that field.

Detokenize reads the value and does not write the original back onto the identity. Updating the identity or its metadata does not clear the tokenization record. A client cannot set or erase `tokenized_fields`.

Turn it on with a `tokenization_secret` that is exactly 32 bytes. See [Server security](/operating/configuration/server-security).

## Tokenizable fields

Identity JSON uses snake_case. Tokenize and detokenize use the PascalCase name. They are not interchangeable. `first_name` returns `IDT_FIELD_NOT_TOKENIZABLE`. `FirstName` is the name Blnk accepts.

| Identity JSON field | Tokenization name |
| :--- | :--- |
| `first_name` | `FirstName` |
| `last_name` | `LastName` |
| `other_names` | `OtherNames` |
| `email_address` | `EmailAddress` |
| `phone_number` | `PhoneNumber` |
| `street` | `Street` |
| `post_code` | `PostCode` |

Use the PascalCase name in the URL and in the `fields` array. Blnk stores a format-preserving token in the field. The token starts with `FPT:` and keeps the shape of the original value, so an email still has an `@` and a domain.

## Tokenize one field

Call [Tokenize field](/reference/tokenize-field). The field must be in the table above, and it must not already be tokenized.

<Tabs>
  <Tab title="Tokenize field">

<CodeGroup>

```bash cURL wrap
curl -X POST "http://localhost:5001/identities/{identity_id}/tokenize/EmailAddress" \
  -H "X-blnk-key: <api-key>"
```

```typescript TypeScript wrap
const response = await blnk.Identity.tokenizeField(
  'idt_3b63c8da-af29-4cc3-ad38-df17d87456e6',
  'EmailAddress',
);
```

```go Go wrap
tokenized, _, _ := client.Identity.TokenizeField(
    "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
    string(blnkgo.TokenizableFieldEmailAddress),
)
```

```python Python wrap
response = blnk.identity.tokenize_field(
  "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
  "EmailAddress",
)
```

```java Java wrap
ApiResponse<JsonNode> response = blnk.identity().tokenizeField(
    "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
    "EmailAddress");
```

</CodeGroup>

| Field | Description | Required |
| :--- | :--- | :--- |
| `identity_id` | Identity that holds the field. | Yes |
| `field` | PascalCase field name, such as `EmailAddress`. | Yes |

  </Tab>
  <Tab title="Response">

```json 200 OK
{
  "message": "Field tokenized successfully"
}
```

| Field | Description |
| :--- | :--- |
| `message` | Confirms the field is now a token. |

  </Tab>
</Tabs>

## Tokenize several fields

### Using the API

Call [Tokenize identity](/reference/tokenize-identity) with at least one field. Blnk tokenizes them in order and stops on the first field that fails.

<Tabs>
  <Tab title="Tokenize identity">

<CodeGroup>

```bash cURL wrap
curl -X POST "http://localhost:5001/identities/{identity_id}/tokenize" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"]
  }'
```

```typescript TypeScript wrap
const response = await blnk.Identity.tokenize(
  'idt_3b63c8da-af29-4cc3-ad38-df17d87456e6',
  {
    fields: ['FirstName', 'LastName', 'EmailAddress', 'PhoneNumber'],
  },
);
```

```go Go wrap
tokenized, _, _ := client.Identity.Tokenize(
    "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
    blnkgo.TokenizeRequest{
        Fields: []blnkgo.TokenizableIdentityField{
            blnkgo.TokenizableFieldFirstName,
            blnkgo.TokenizableFieldLastName,
            blnkgo.TokenizableFieldEmailAddress,
            blnkgo.TokenizableFieldPhoneNumber,
        },
    },
)
```

```python Python wrap
response = blnk.identity.tokenize(
  "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
  {
    "fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"],
  },
)
```

```java Java wrap
ApiResponse<JsonNode> response = blnk.identity().tokenize(
    "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
    TokenizeIdentityData.create()
        .fields(List.of("FirstName", "LastName", "EmailAddress", "PhoneNumber")));
```

</CodeGroup>

| Field | Description | Required |
| :--- | :--- | :--- |
| `identity_id` | Identity that holds the fields. | Yes |
| `fields` | PascalCase names to tokenize. At least one. | Yes |

  </Tab>
  <Tab title="Response">

```json 200 OK
{
  "message": "Fields tokenized successfully"
}
```

| Field | Description |
| :--- | :--- |
| `message` | Confirms every field in the request is now a token. |

  </Tab>
</Tabs>

## Read several fields back

### Using the API

Call [Detokenize identity](/reference/detokenize-identity). The keys in the response are the names you sent. Omit `fields`, or send an empty array, to read every tokenized field.

<Tabs>
  <Tab title="Detokenize identity">

<CodeGroup>

```bash cURL wrap
curl -X POST "http://localhost:5001/identities/{identity_id}/detokenize" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"]
  }'
```

```typescript TypeScript wrap
const response = await blnk.Identity.detokenize(
  'idt_3b63c8da-af29-4cc3-ad38-df17d87456e6',
  {
    fields: ['FirstName', 'LastName', 'EmailAddress', 'PhoneNumber'],
  },
);
```

```go Go wrap
detokenized, _, _ := client.Identity.Detokenize(
    "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
    blnkgo.DetokenizeRequest{
        Fields: []blnkgo.TokenizableIdentityField{
            blnkgo.TokenizableFieldFirstName,
            blnkgo.TokenizableFieldLastName,
            blnkgo.TokenizableFieldEmailAddress,
            blnkgo.TokenizableFieldPhoneNumber,
        },
    },
)
```

```python Python wrap
response = blnk.identity.detokenize(
  "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
  {
    "fields": ["FirstName", "LastName", "EmailAddress", "PhoneNumber"],
  },

```

```java Java wrap
ApiResponse<JsonNode> response = blnk.identity().detokenize(
    "idt_3b63c8da-af29-4cc3-ad38-df17d87456e6",
    DetokenizeIdentityData.create()
        .fields(List.of("FirstName", "LastName", "EmailAddress", "PhoneNumber")));
```

</CodeGroup>

| Field | Description | Required |
| :--- | :--- | :--- |
| `identity_id` | Identity that holds the tokens. | Yes |
| `fields` | PascalCase names to read. Omit to read every tokenized field. | No |

  </Tab>
  <Tab title="Response">

```json 200 OK

  "fields": {
    "FirstName": "Alice",
```

## Errors

<Version>Structured errors are available from Blnk Core 0.15.0 and later.</Version>

| Code | When it happens |
| :--- | :--- |
| `IDT_FIELD_NOT_TOKENIZABLE` | The name is not in the [tokenizable set](#tokenizable-fields), or the casing is wrong. |
| `IDT_FIELD_ALREADY_TOKENIZED` | You tokenize a field that is already a token. |
| `IDT_FIELD_NOT_TOKENIZED` | You detokenize a field that is not a token. |
| `IDT_TOKENIZATION_DISABLED` | `tokenization_secret` is missing or is not 32 bytes. |

```json 400 Bad Request
{
  "error": "field first_name is not tokenizable",
  "error_detail": {
    "code": "IDT_FIELD_NOT_TOKENIZABLE",
    "message": "field first_name is not tokenizable"
  }
}
```

| Code | What to do |
| :--- | :--- |
| `IDT_FIELD_NOT_TOKENIZABLE` | Use the PascalCase name, such as `/tokenize/FirstName`. |
| `IDT_FIELD_ALREADY_TOKENIZED` | Skip it, or detokenize first if you need the original value. |
| `IDT_FIELD_NOT_TOKENIZED` | Tokenize the field before you detokenize it. |
| `IDT_TOKENIZATION_DISABLED` | Set `tokenization_secret` to a 32-byte value and restart Core. |

For the full list, see [API error codes](/operating/error-codes).
