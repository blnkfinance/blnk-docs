An identity is a customer on your ledger, either an individual or an organization. Create one, then link it to a balance so the transactions on that balance belong to the same customer.

<Warning>
**Identities in Blnk are not a replacement for KYC verification.** They store customer data on the ledger. Use a third-party provider when you need to verify that data.
</Warning>

## Create an identity

Blnk stores two identity types, `individual` and `organization`. Fields that are specific to your application go in `meta_data`.

### Using the API

Call [Create identity](/reference/create-identity):

<Note>
Leave `identity_id` out and Blnk generates one. Pass your own when it should match a holder reference you already have. It must start with `idt_` and a valid UUID, such as `idt_8cc22560-5ace-4989-8953-fcbad7947d48`. A duplicate returns `400` with `IDT_VALIDATION_ERROR`.
</Note>

<Tabs>
  <Tab title="Create identity">

<CodeGroup>

```bash cURL wrap
curl -X POST "http://localhost:5001/identities" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "identity_type": "individual",
    "first_name": "Alice",
    "last_name": "Smith",
    "other_names": "Marie",
    "gender": "female",
    "dob": "1985-05-15T00:00:00Z",
    "email_address": "alice.smith@example.com",
    "phone_number": "+1234567890",
    "nationality": "Canadian",
    "category": "customer",
    "street": "789 Elm St",
    "country": "Canada",
    "state": "Ontario",
    "post_code": "M4B 1B3",
    "city": "Toronto",
    "meta_data": {
      "customer_id": "CUST123456",
      "membership_level": "Gold"
    }
  }'
```

```java Java wrap
    IdentityData.create()

        .firstName("Alice")

        .gender("female")
        .dob("1985-05-15T00:00:00Z")
        .emailAddress("alice.smith@example.com")
        .phoneNumber("+1234567890")
        .nationality("Canadian")
        .category("customer")
        .street("789 Elm St")
        .country("Canada")
        .state("Ontario")
        .postCode("M4B 1B3")

            "membership_level", "Gold"
        )));
```

</CodeGroup>

| Field | Description | Required |
| :--- | :--- | :--- |
| `identity_type` | `individual` or `organization`. | No |
| `organization_name` | Name of the organization. | No |
| `first_name` | First name of the individual. | No |
| `last_name` | Last name of the individual. | No |
| `other_names` | Other names linked to the individual. | No |
| `gender` | Gender of the individual. | No |
| `dob` | Date of birth, as an ISO 8601 timestamp. | No |
| `email_address` | Email address. | No |
| `phone_number` | Contact number. | No |
| `nationality` | Nationality of the individual. | No |
| `category` | A label for this customer, such as `customer` or `vip`. | No |
| `street` | Street address. | No |
| `country` | Country. | No |
| `state` | State or region. | No |
| `post_code` | Postal code. | No |
| `city` | City. | No |
| `meta_data` | Custom metadata. | No |
| `identity_id` | Your own id. Leave it out and Blnk generates one. | No |

### Using the Dashboard

You can also create an identity from the dashboard.

<Steps titleSize="h3">
<Step title="Open Create identity">

On **Identities**, click **Create identity** in the top right. You can also press `⌥ I` (`Alt+I` on Windows).

![Identities table with Create identity in the header](img/identities/create-identity-open.png)

</Step>

<Step title="Choose the identity type">

Select **Individual** for a person or **Organization** for a business.

![Create identity form with Individual or Organization selected](img/identities/create-identity-type.png)

</Step>

<Step title="Enter the profile">

Fill in the fields the form asks for:

- **Individual:** first name, last name, and email address
- **Organization:** organization name and email address

The other profile and address fields are optional.

![Create identity form with name and email filled in](img/identities/create-identity-details.png)

</Step>

<Step title="Add metadata">

This step is optional. Scroll to **Metadata**.

- Click **Add metadata** to add a key and value for this identity.
- Click **Use template** to import keys from a metadata template.

![Create identity form with the Metadata section](img/identities/create-identity-metadata.png)

</Step>

<Step title="Create the identity">

Click **Create identity**.

![Identities table showing a newly created identity](img/identities/create-identity-result.png)

</Step>
</Steps>

The new identity appears in the Identities table. Open it to see the full profile.

## Update an identity

### Using the API

Call [Edit identity](/reference/edit-identity) with the `identity_id`. 

Send only the fields you want to change. Blnk skips an empty string, so the stored value stays. When you send `meta_data`, it replaces the object stored on the identity.

<Tabs>
  <Tab title="Update identity">

<CodeGroup>

```bash cURL wrap
curl -X PUT "http://localhost:5001/identities/{identity_id}" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "email_address": "alice.smith@example.com",
    "phone_number": "+1234567890"
  }'
```

```typescript TypeScript wrap
const response = await blnk.Identity.update('{identity_id}', {
  email_address: 'alice.smith@example.com',
  phone_number: '+1234567890',
});
```

```go Go wrap
identity, resp, err := client.Identity.Update(
    "idt_8cc22560-5ace-4989-8953-fcbad7947d48",
    &blnkgo.Identity{
        EmailAddress: "alice.smith@example.com",
        PhoneNumber: "+1234567890",
    },
)
```

```python Python wrap
response = blnk.identity.update("{identity_id}", {
  "email_address": "alice.smith@example.com",
  "phone_number": "+1234567890",
})
```

```java Java wrap
ApiResponse<JsonNode> response = blnk.identity().update(
    "{identity_id}",
    IdentityData.create()
        .emailAddress("alice.smith@example.com")
        .phoneNumber("+1234567890"));
```

</CodeGroup>

  </Tab>
  <Tab title="Response">

```json 200 OK
{
  "message": "Identity updated successfully"
}
```

| Field | Description |
| :--- | :--- |
| `message` | Confirms the identity was updated. |

  </Tab>
</Tabs>

### Using the Dashboard

Open the identity and click **Edit identity** in the top right. Update the profile, contact, or address fields, then save.
