An order exchange holds each side until the orders match, then settles them. Alice offers 1,000 USDC for 0.01 BTC, and Bob offers 0.01 BTC for 1,000 USDC.

This tutorial shows how to implement that with Blnk.

<TutorialSteps>
  <TutorialStep title="Design the money movement">
    Before we start building, we need to define our [money movement](/ledgers/money-movement-map). This helps us outline how the two orders meet.

    Alice's USDC is held in `@USDC_Escrow`, and Bob's BTC is held in `@BTC_Escrow`. Both holds are [inflight](/transactions/inflight/create-inflight), so the funds stay reserved until the orders match.

    Settlement commits those holds, then moves the BTC from escrow to Alice and the USDC from escrow to Bob.

      <Map src="https://map.blnkfinance.xyz/VZQ6TdCPik" title="Order exchange money movement" />
    </TutorialFrame>
  </TutorialStep>

  <TutorialStep title="Create the USDC ledger">
    Before we start recording transactions, we need a [ledger](/ledgers/introduction) for USDC balances, separate from BTC. Each currency stays in its own ledger so the balances roll up on their own.

    The escrow balances are created in the [General Ledger](/ledgers/general-ledger) when the orders are placed.

    Create the USDC ledger:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/ledgers" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "{{name}}",
    "meta_data": {
      "description": "{{description}}"
    }
  }'
```

```typescript TypeScript wrap
const response = await blnk.Ledgers.create({
  name: '{{name}}',
  meta_data: {
    description: '{{description}}',
  },
});
```

```go Go wrap
    Name: "{{name}}",
    MetaData: blnkgo.MetaData{

```

  <TutorialStep title="Create Alice's identity">

    Anything else we want to keep goes in [metadata](/search/metadata). We'll store her customer id there as `customer_id`. Her USDC and BTC balances both use this identity.

    Create Alice's identity:

<TutorialCode>

  <TutorialStep title="Fund Alice's USDC">
    Alice starts with 1,000 USDC, funded from `@USDC_FundingPool`. USDC has 6 decimal places, so [precision](/transactions/precision) is `1000000`, and 1,000 USDC is `precise_amount` `1000000000`.

    <Note>
      To make sure the funding applies, we turn on [overdraft](/transactions/overdrafts). Without it, `@USDC_FundingPool` is created with a 0 balance, and Blnk would reject the record.
    </Note>

    Fund Alice's USDC:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/transactions" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "precise_amount": {{precise_amount}},
    "precision": 1000000,
    "reference": "ORD-USDC-20261019-090000",
    "description": "Initial USDC funding",
    "currency": "{{currency}}",
    "source": "{{source}}",
    "destination": "{{destination}}",
    "allow_overdraft": true
  }'
```

```typescript TypeScript wrap
const amount = {{amount}};
const precision = 1000000;
const precise_amount = Math.round(amount * precision);

  precise_amount,
  precision,
  reference: 'ORD-USDC-20261019-090000',
  description: 'Initial USDC funding',
  currency: '{{currency}}',
  source: '{{source}}',
  destination: '{{destination}}',
  allow_overdraft: true,
});
```
