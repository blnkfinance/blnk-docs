A loan balance tracks what a customer owes. Disbursement moves the principal onto their main balance, interest increases what they owe, and a repayment pays it down.

This tutorial shows how to implement that with Blnk.

<TutorialSteps>
  <TutorialStep title="Design the money movement">
    Before we start building, we need to define our [money movement](/ledgers/money-movement-map). This helps us outline how a loan is disbursed, charged, and repaid.

    Alice borrows \$500.00. The source is her loan balance, and the destination is her main balance. [Overdraft](/transactions/overdrafts) lets the loan balance go negative, and that negative amount is what she owes.

    One day later we charge \$5.00 of interest from the loan balance to `@InterestRevenue`. Alice then repays \$200.00 from her main balance back to the loan balance.

  <TutorialStep title="Create the customer ledger">
    Before we start recording transactions, we need a [ledger](/ledgers/introduction) for customer main balances, separate from the ledger that holds what they owe.

    For our lending example, we only support one currency, USD. Therefore, we'll create a ledger to manage all USD main balances belonging to our customers.

    Create the customer ledger:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/ledgers" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "{{name}}",
    "meta_data": {
      "description": "{{description}}"
    }
  }'
```

```typescript TypeScript wrap
const response = await blnk.Ledgers.create({
  name: '{{name}}',
  meta_data: {
    description: '{{description}}',
  },
});
```

```go Go wrap
ledger, _, _ := client.Ledger.Create(blnkgo.CreateLedgerRequest{
    Name: "{{name}}",
    MetaData: blnkgo.MetaData{
        "description": "{{description}}",
    },
})
```

  <TutorialStep title="Create an identity">
    An [identity](/identities/introduction) is how we record the customer. We pass Alice's type, name, email, and phone number.

    Anything else we want to keep goes in [metadata](/search/metadata). We'll store her customer id there as `customer_id`. Both balances use this same identity.

    Create the identity:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/identities" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "identity_type": "individual",
    "first_name": "{{first_name}}",
    "last_name": "{{last_name}}",
    "email_address": "{{email_address}}",
    "phone_number": "{{phone_number}}",
    "meta_data": {
      "customer_id": "{{customer_id}}"
    }
  }'
```

  <TutorialStep title="Disburse the loan">
    Alice borrows \$500.00. We debit her loan balance and credit her main balance, so she receives the funds and the loan balance shows what she owes.

    The amount is a decimal, and we multiply it by [precision](/transactions/precision) `100` to get `precise_amount`. The reference and the description are already set.

    <Note>
      The loan balance starts at 0, so we turn on [overdraft](/transactions/overdrafts). That is what lets it go to -\$500.00.
    </Note>

    Disburse the loan:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/transactions" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "precise_amount": {{precise_amount}},
    "precision": 100,
    "reference": "LOAN-20261019-103000",
    "description": "Loan disbursement",
    "currency": "{{currency}}",
    "source": "{{source}}",
    "destination": "{{destination}}",
    "allow_overdraft": true
  }'
```

```typescript TypeScript wrap
const amount = {{amount}};
const precision = 100;
const precise_amount = Math.round(amount * precision);

const response = await blnk.Transactions.create({
  precise_amount,
  precision,
  reference: 'LOAN-20261019-103000',
  description: 'Loan disbursement',
  currency: '{{currency}}',
  source: '{{source}}',
  destination: '{{destination}}',
  allow_overdraft: true,
});
```

```go Go wrap
amount := {{amount}}

        Description: "Loan disbursement",
```

  <TutorialStep title="Charge interest">
    Interest is money Alice owes on top of the principal. We debit the loan balance again and credit `@InterestRevenue`, an internal balance for interest earned.

    For this example the charge is \$5.00, which is 1% of the \$500.00 principal for the day. The loan balance moves from -\$500.00 to -\$505.00.

    <Tip>
      Repeat this step each day the loan is open, with a new reference and the interest for that day.
    </Tip>
