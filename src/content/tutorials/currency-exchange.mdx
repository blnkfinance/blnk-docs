A currency exchange is two transactions, one for each currency. Alice gives up USD, and a nostro balance pays her the GBP. Both legs are one atomic batch, so they succeed or fail together.

This tutorial shows how to implement that with Blnk.

<TutorialSteps>
  <TutorialStep title="Design the money movement">
    Before we start building, we need to define our [money movement](/ledgers/money-movement-map). This helps us outline how one currency becomes another.

    Alice converts \$1,000.00 to GBP. At \$1.00 = £0.79, she receives £790.00. Her USD balance pays `@NostroUSD`, and `@NostroGBP` pays her GBP balance.

    Both are [internal balances](/balances/internal-balances) in the General Ledger. We send them in one [bulk](/transactions/bulk-transactions) request with `atomic` set, so a failed GBP leg does not leave her USD already taken.

  <TutorialStep title="Create a ledger">
    Before we start recording transactions, we need to set up our [ledger](/ledgers/introduction) to track customers and their balances.

    Alice holds USD and GBP in the same ledger. The nostro balances are created in the [General Ledger](/ledgers/general-ledger) when we record the exchange.

    Create the ledger:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/ledgers" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "{{name}}",
    "meta_data": {
      "description": "{{description}}"
    }
  }'
```

```typescript TypeScript wrap
const response = await blnk.Ledgers.create({
  name: '{{name}}',
  meta_data: {
    description: '{{description}}',
  },
});
```

```go Go wrap
    Name: "{{name}}",
    MetaData: blnkgo.MetaData{
        "description": "{{description}}",

```

  <TutorialStep title="Create an identity">

    Anything else we want to keep goes in [metadata](/search/metadata). We'll store her customer id there as `customer_id`. Both currency balances use this same identity.

  <TutorialStep title="Record a deposit">
    Alice deposits \$1,000.00 before she converts. The source is `@WorldUSD`, and the destination is her USD balance.

    The amount is a decimal, and we multiply it by [precision](/transactions/precision) `100` to get `precise_amount`. The reference and the description are already set.

    <Note>
      To make sure the deposit applies, we need to turn on [overdraft](/transactions/overdrafts). Without it, `@WorldUSD` is created with a 0 balance, and Blnk would reject the record because the source has insufficient funds.
    </Note>

    Record the deposit:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/transactions" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "precise_amount": {{precise_amount}},
    "precision": 100,
    "reference": "FX-DEP-20261019-103000",
    "description": "USD deposit",
    "currency": "{{currency}}",
    "source": "{{source}}",
    "destination": "{{destination}}",
    "allow_overdraft": true
  }'
```

  <TutorialStep title="Exchange the currencies">
    We record both legs in one request to `POST /transactions/bulk`. The USD leg debits Alice and credits `@NostroUSD`. The GBP leg debits `@NostroGBP` and credits Alice.

    Each amount is a decimal, and we multiply it by precision `100`. The references and the description are already set. `@NostroGBP` starts at 0, so that leg turns on overdraft.

    <Note>
      `atomic` means Blnk rolls the batch back if either leg fails. The batch is queued, and each leg is linked to the same `batch_id`.
    </Note>

    <Tip>
      If Alice receives £770.00 instead of £790.00, add a third leg in the same batch from `@NostroGBP` to `@SpreadGBP` for the £20.00 you keep. Set `inflight` on the bulk request when you want to hold both legs until the rate is confirmed.
    </Tip>

    Exchange the currencies:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/transactions/bulk" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "atomic": true,
    "transactions": [
      {
        "precise_amount": {{usd_amount_precise}},
        "precision": 100,
        "reference": "FX-USD-20261019-103000",
        "description": "USD to GBP conversion",
        "currency": "USD",
        "source": "{{usd_source}}",
        "destination": "@NostroUSD"
      },
      {
        "precise_amount": {{gbp_amount_precise}},
        "precision": 100,
        "reference": "FX-GBP-20261019-103000",
        "description": "USD to GBP conversion",
        "currency": "GBP",
        "source": "@NostroGBP",
        "destination": "{{gbp_destination}}",
        "allow_overdraft": true
      }
    ]
  }'
```

```typescript TypeScript wrap
const usdAmount = {{usd_amount}};
```
