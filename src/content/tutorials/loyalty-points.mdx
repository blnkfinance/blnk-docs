Loyalty points are a balance a customer earns on a purchase and spends on a later one. Awarding points issues them from a pool, and redeeming points returns them to that pool.

This tutorial shows how to implement that with Blnk.

<TutorialSteps>
  <TutorialStep title="Design the money movement">
    Before we start building, we need to define our [money movement](/ledgers/money-movement-map). Alice pays for a purchase from her USD balance, and we award points from a pool into her points balance.

    A purchase of \$100.00 moves from Alice to `@RevenueUSD`. We then issue 10 points from `@PointsPool` to her points balance, one point for every \$10 she spends.

    When she buys again, those points move back to `@PointsPool`. Ten points are worth \$1.00, so a \$20.00 purchase costs her \$19.00 from her USD balance.

  <TutorialStep title="Create a ledger">
    Before we start recording transactions, we need to set up our [ledger](/ledgers/introduction) to track Alice's USD balance and her points balance.

    For our example, she holds both in one ledger. We'll create that ledger for the two balances.

    <Tip>
      `@RevenueUSD` and `@PointsPool` are created in the [General Ledger](/ledgers/general-ledger) when we record the purchase and the award, separate from this customer ledger.
    </Tip>

    Create the ledger:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/ledgers" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "{{name}}",
    "meta_data": {
      "description": "{{description}}"
    }
  }'
```

```typescript TypeScript wrap
const response = await blnk.Ledgers.create({
  name: '{{name}}',
  meta_data: {
    description: '{{description}}',
  },
});
```

```go Go wrap
ledger, _, _ := client.Ledger.Create(blnkgo.CreateLedgerRequest{
    Name: "{{name}}",
    MetaData: blnkgo.MetaData{
        "description": "{{description}}",
    },
})
```


  <TutorialStep title="Create an identity">
    An [identity](/identities/introduction) is how we record the customer. We pass Alice's type, name, email, and phone number.

    Anything else we want to keep goes in [metadata](/search/metadata). We'll store her customer id there as `customer_id`.

    Create the identity:

<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/identities" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "identity_type": "individual",
    "first_name": "{{first_name}}",
    "last_name": "{{last_name}}",
    "email_address": "{{email_address}}",
    "phone_number": "{{phone_number}}",
    "meta_data": {
      "customer_id": "{{customer_id}}"
    }
  }'
```

  <TutorialStep title="Record a deposit">
    Alice deposits \$120.00 via an ACH transfer so she can pay for both purchases. The destination is her USD balance, and the source is `@WorldUSD_ACH`.

    The amount is a decimal, and we multiply it by [precision](/transactions/precision) `100` to get `precise_amount`. The reference and the description are already set.

    <Note>
      To make sure the transaction applies, we need to turn on [overdraft](/transactions/overdrafts). Without it, `@WorldUSD_ACH` is created with a 0 balance, and Blnk would reject the record because the source has insufficient funds.
    </Note>

    Record the deposit:

<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/transactions" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "precise_amount": {{precise_amount}},
    "precision": 100,
    "reference": "DEP-20261019-090000",
    "description": "ACH deposit",
    "currency": "{{currency}}",
    "source": "{{source}}",
    "destination": "{{destination}}",
    "allow_overdraft": true
  }'
```

```typescript TypeScript wrap
const amount = {{amount}};
const precision = 100;
const precise_amount = Math.round(amount * precision);

const response = await blnk.Transactions.create({

  description: 'ACH deposit',
  currency: '{{currency}}',

  destination: '{{destination}}',
  allow_overdraft: true,
});
```

  <TutorialStep title="Award the points">

    Points use [precision](/transactions/precision) `1`, so 10 points is `precise_amount` `10`. We'll store the purchase reference in [metadata](/search/metadata) as `purchase_reference`.
