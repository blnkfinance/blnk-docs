A card payment reserves the amount when the network authorizes it, then takes the money when the processor settles it. The hold is an inflight transaction, and settlement commits that hold.

This tutorial shows how to implement that with Blnk.

<TutorialSteps>
  <TutorialStep title="Design the money movement">
    Before we start building, we need to define our [money movement](/ledgers/money-movement-map). This helps us outline how a card payment leaves Alice's balance.

    Alice pays \$20.00 to a merchant. The source is her card balance, and the destination is `@WorldUSD`, an [internal balance](/balances/internal-balances) for money that leaves the system.

    We record the payment with [inflight](/transactions/inflight/create-inflight) set, so the \$20.00 stays reserved until the processor settles it. Her available balance drops by \$20.00 while the hold is open.

  </TutorialStep>

  <TutorialStep title="Create a ledger">
    Before we start recording transactions, we need to set up our [ledger](/ledgers/introduction) to track customers and their card balances.

    For our card example, we only support one currency, USD. Therefore, we'll create a ledger to manage all USD card balances belonging to our customers.

    <Tip>
      `@WorldUSD` is created in the [General Ledger](/ledgers/general-ledger) when we load the card, separate from this customer ledger.
    </Tip>

    Create the ledger:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/ledgers" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "name": "{{name}}",
    "meta_data": {
      "description": "{{description}}"
    }
  }'
```

```typescript TypeScript wrap
const response = await blnk.Ledgers.create({
  name: '{{name}}',
  meta_data: {
    description: '{{description}}',
  },
});
```

```go Go wrap
ledger, _, _ := client.Ledger.Create(blnkgo.CreateLedgerRequest{
    Name: "{{name}}",
    MetaData: blnkgo.MetaData{
        "description": "{{description}}",
    },
})
```

```python Python wrap
response = blnk.ledgers.create({

    "description": "{{description}}",
  },
})
```

```java Java wrap

```

  <TutorialStep title="Create an identity">
    An [identity](/identities/introduction) is how we record the customer. We pass Alice's type, name, email, and phone number.

    Anything else we want to keep goes in [metadata](/search/metadata). We'll store her customer id there as `customer_id`.

    Create the identity:

  <TutorialStep title="Load the card">
    Alice loads \$100.00 onto the card before she spends. The source is `@WorldUSD`, and the destination is her card balance.

    The amount is a decimal, and we multiply it by [precision](/transactions/precision) `100` to get `precise_amount`. The reference and the description are already set.

    <Note>
      To make sure the load applies, we need to turn on [overdraft](/transactions/overdrafts). Without it, `@WorldUSD` is created with a 0 balance, and Blnk would reject the record because the source has insufficient funds.
    </Note>

    Load the card:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X POST "{{CORE_URL}}/transactions" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "precise_amount": {{precise_amount}},
    "precision": 100,
    "reference": "CRD-DEP-20261019-103000",
    "description": "Card load",
    "currency": "{{currency}}",
    "source": "{{source}}",
    "destination": "{{destination}}",
    "allow_overdraft": true
  }'
```

```typescript TypeScript wrap
const amount = {{amount}};
const precision = 100;
const precise_amount = Math.round(amount * precision);

const response = await blnk.Transactions.create({
  precise_amount,
  precision,
  reference: 'CRD-DEP-20261019-103000',
  description: 'Card load',
  currency: '{{currency}}',
  source: '{{source}}',
  destination: '{{destination}}',
  allow_overdraft: true,
});
```

  <TutorialStep title="Authorize the payment">
    The network asks whether Alice can cover \$20.00. We record an inflight transaction from her card balance to `@WorldUSD`, which reserves the amount without applying it yet.

    While the hold is open, that \$20.00 is not available for another payment. A new transaction larger than the remaining \$80.00 is rejected.

  <TutorialStep title="Commit the payment">
    The processor settles the payment, so we [commit](/transactions/inflight/commit-inflight) the hold. We send `commit` for the transaction from the previous step, and the \$20.00 leaves Alice's card.

    <Note>
      Blnk queues the commit. The response stays `INFLIGHT` until the worker applies it, and then the card balance shows \$80.00.
    </Note>

    <Tip>
      If the payment is reversed, [void](/transactions/inflight/void-inflight) the hold instead, and Alice keeps the \$20.00. To settle part of it, commit a `precise_amount`, and the rest stays inflight.
    </Tip>

    Commit the payment:

<TutorialCode>
<CodeGroup>

```bash cURL wrap
curl -X PUT "{{CORE_URL}}/transactions/inflight/{{transaction_id}}" \
  -H "X-blnk-key: {{CORE_SECRET_KEY}}" \
  -H "Content-Type: application/json" \
  -d '{
    "status": "commit"
  }'
```

```typescript TypeScript wrap
const response = await blnk.Transactions.updateStatus(
  '{{transaction_id}}',
  {
    status: 'commit',
  },
);
```

```go Go wrap
transaction, _, _ := client.Transaction.Update(
    "{{transaction_id}}",
    blnkgo.UpdateStatus{
        Status: blnkgo.InflightStatusCommit,
    },
)
```

```python Python wrap
response = blnk.transactions.update_status(
  "{{transaction_id}}",
  {
    "status": "commit",
  },
)
```

```java Java wrap
ApiResponse<JsonNode> response = blnk.transactions().updateStatus(
    "{{transaction_id}}",
    UpdateTransactionStatus.create()
        .status("commit"));
```
