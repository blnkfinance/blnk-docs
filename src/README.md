# Source

| Folder | What it is |
| --- | --- |
| [assets](assets/README.md) | Fonts |
| [content](content/README.md) | The documentation pages |
| [icons](icons/README.md) | Icons used in the docs |
| [lib](lib/README.md) | Titles, the table of contents, code blocks, and images |
| [pages](pages/README.md) | Routes the site builds |
| [styles](styles/README.md) | CSS |
| [ui](ui/README.md) | The page chrome and the MDX tags |

`content.config.ts` is the frontmatter for a page: title, description, the API method and path, and `enterprise`.
