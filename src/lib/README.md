# Lib

Helpers the pages and the layout call.

| File | What it does |
| --- | --- |
| `seo.ts` | The document title, meta description, sitemap, and `llms.txt` |
| `toc.ts` | The "on this page" list. A tab title sits under the heading it follows |
| `fence-meta.ts` | The title, wrap, and line highlight on a code block |
| `remark-content-images.ts` | Turns `img/...` in a page into a path the site can serve |
