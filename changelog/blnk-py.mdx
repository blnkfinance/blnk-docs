<Update label="1.5.0" description="Sep 24, 2026">
  <Info>
  `blnk-python@1.5.0` targets Blnk Core **0.15.4**.
  </Info>

  ### Error handling

  `BlnkErrorCode` now includes the full Core catalogue. Branch on `response.error.code`. See [API error codes](/advanced/error-codes) and the [0.15.4 migration guide](/changelog/v15-4-migration).

  Codes introduced or re-routed in 0.15.4:

  - `TXN_ALREADY_REFUNDED` (`409`): refunding a transaction twice, or refunding a refund.
  - `BAL_NOT_FOUND` (`404`): a transaction naming a missing balance. Previously `TXN_NOT_FOUND`.
  - `TXN_VALIDATION_ERROR` (`400`) is also returned for a split that has both `sources` and `destinations`.
  - `GEN_CONFLICT` (`409`) is also returned when a mixed-leg refund fails.

  ### Search

  `search.multi_search` sends several Typesense searches in one `POST /multi-search` request. See [Search via Typesense](/reference/search-typesense) and the [Python search page](/sdks/python/search/search-typesense).

  ### List

  `ledgers.list`, `ledger_balances.list`, `transactions.list`, and `balance_monitor.list_by_balance_id` wrap `GET /ledgers`, `GET /balances`, `GET /transactions`, and `GET /balance-monitors/balances/:id`.

  ### Before you upgrade

  - You need Core **0.15.4** for these features.
</Update>

<Update label="1.4.0" description="Sep 3, 2026">
  <Info>
  `blnk-python@1.4.0` targets Blnk Core **0.15.3**.
  </Info>

  ### Transactions

  Preview a create, bulk, refund, or inflight update without writing anything. Pass `dry_run: True` and Core returns whether it would apply and how balances would change. The reference is still free to use on a real post. See [Dry-run transactions](/transactions/dry-run).

  Refunds can take a description and metadata. An empty description inherits the original. Metadata is merged onto the inherited copy.

  ### Balances

  Create a General Ledger balance yourself by passing an `@` indicator with `ledger_id` set to `general_ledger_id`. See [Internal balances](/balances/internal-balances).

  ### Hooks

  Listing hooks without a type now returns PRE and POST hooks.

  ### Error handling

  Named codes for invalid amounts, validation failures, and General Ledger conflicts are on `BlnkErrorCode`. Branch on `response.error.code`.

  ### Before you upgrade

  - You need Core **0.15.3** for these features.
  - A preview that would be rejected is still HTTP 200. Check `would_apply` before you treat the call as a posted transaction.
</Update>

<Update label="1.3.0" description="Jul 8, 2026">
  <Info>
  `blnk-python@1.3.0` covers Blnk Core **0.15.0**.
  </Info>

  Initial public release of the Python SDK with full parity against the TypeScript SDK.

  ### Coverage

  Ledgers, ledger balances (including monitors, snapshots, historical balances, and lineage), transactions (bulk, inflight, refunds, queue recovery), reconciliation, identities and PII tokenization, search and reindex, metadata, hooks, API keys, and system health.

  ### Client

  Sync client built on `requests` with configurable timeouts, GET-only retries, structured `ApiResponse` envelopes, and redacted logging.

  ### Core 0.15.0

  Structured error codes on `response.error.code`. Inflight commit and void run through the queue by default; pass `skip_queue` for synchronous results.

  ### Before you upgrade Core

  Note the following breaking changes in Core 0.15.0:

  - Transaction and balance responses no longer include `rate` or `currency_multiplier`.
  - Branch on `response.error.code` for Core failures. Do not parse error message text.
</Update>
