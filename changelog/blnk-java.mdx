<Update label="1.5.0" description="Sep 24, 2026">
  <Info>
  `com.blnkfinance:blnk-java:1.5.0` targets Blnk Core **0.15.4**.
  </Info>

  ### Transactions

  A second refund of the same transaction is rejected instead of reversing the first. A source or destination that does not exist is reported as a missing balance, not a missing transaction. A split cannot include both `sources` and `destinations`. See the [0.15.4 migration guide](/changelog/v15-4-migration).

  ### Search

  Search more than one collection in a single request with `search().multiSearch()`. See [Search via Typesense](/sdks/java/search/search-typesense).

  ### Ledgers

  List ledgers, balances, and transactions. List the monitors on one balance with `balanceMonitor().listByBalanceId()`.

  ### Error handling

  Named codes for the full Core catalogue are on `BlnkErrorCodes`. Branch on `response.error().code()`. See [API error codes](/advanced/error-codes).

  ### Before you upgrade

  - You need Core **0.15.4** for these features.
  - Keep using `com.blnkfinance:blnk-java`. Change only the version to `1.5.0`.
</Update>

<Update label="1.4.0" description="Sep 4, 2026">
  <Info>
  `com.blnkfinance:blnk-java:1.4.0` targets Blnk Core **0.15.3**.
  </Info>

  ### Transactions

  Preview a create, bulk, refund, or inflight update without writing anything. Call `dryRun(true)` on the request. Core returns whether it would apply and how balances would change. The reference is still free to use on a real post. See [Dry-run transactions](/transactions/dry-run).

  Refunds can take a description and metadata. An empty description inherits the original. Metadata is merged onto the inherited copy.

  ### Balances

  Create a General Ledger balance yourself by passing an `@` indicator with `ledgerId` set to `general_ledger_id`. See [Internal balances](/balances/internal-balances).

  ### Hooks

  Listing hooks without a type now returns PRE and POST hooks.

  ### Error handling

  Named codes for invalid amounts and General Ledger conflicts are on `BlnkErrorCodes`. Branch on `response.error().code()`.

  ### Before you upgrade

  - You need Core **0.15.3** for these features.
  - Keep using `com.blnkfinance:blnk-java`. Change only the version to `1.4.0`.
</Update>

<Update label="1.3.0" description="Jul 8, 2026">
  <Info>
  `com.blnkfinance:blnk-java:1.3.0` covers Blnk Core **0.15.0**.
  </Info>

  Initial public release of the Java SDK with full parity against the TypeScript SDK.

  ### Coverage

  Ledgers, ledger balances (including monitors, snapshots, historical balances, and lineage), transactions (bulk, inflight, refunds, queue recovery), reconciliation, identities and PII tokenization, search and reindex, metadata, hooks, API keys, and system health.

  ### Client

  Sync client built on the JDK `java.net.http.HttpClient` and Jackson, with `Blnk.init` / `BlnkClientOptions.builder()`, configurable timeouts, GET-only retries, structured `ApiResponse` envelopes, and redacted logging. Services use camelCase accessors such as `transactions().create()` and fluent request builders in `com.blnkfinance.blnk.types`.

  ### Core 0.15.0

  Structured error codes on `response.error().code()`. Inflight commit and void run through the queue by default; pass `skipQueue` for synchronous results.

  ### Before you upgrade Core

  Note the following breaking changes in Core 0.15.0:

  - Transaction and balance responses no longer include `rate` or `currency_multiplier`.
  - Branch on `response.error().code()` for Core failures. Do not parse error message text.
</Update>
