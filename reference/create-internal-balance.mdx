<Info>Available in version 0.15.3 and later.</Info>

Create an [internal balance](/balances/internal-balances) in the General Ledger by passing `ledger_id` as `general_ledger_id` and an `indicator` that starts with `@`.

If you later reference an `@` indicator that does not exist yet in a transaction, Blnk still creates that balance automatically.

### Body
<ParamField body="ledger_id" type="string" required>
  Must be `general_ledger_id`. `indicator` is only allowed on the General Ledger.
</ParamField>
<ParamField body="currency" type="string" required>
  The currency/asset class of this balance. See the following: [Currencies](/guides/currencies)
</ParamField>
<ParamField body="indicator" type="string" required>
  Unique name for the internal balance. Must start with `@` and contain no whitespace (for example `@Revenue`). The same indicator and currency pair can only exist once.
</ParamField>
<ParamField body="identity_id" type="string">
  Unique id of identity (if any) to be linked to the balance. Can be left out from the request body if there's no identity to be linked.
</ParamField>
<ParamField body="track_fund_lineage" type="boolean" default="false">
  Enables fund lineage tracking on this balance.

  <Warning>
    Fund lineage requires `identity_id`.
  </Warning>
</ParamField>
<ParamField body="allocation_strategy" type="string" default="FIFO">
  Controls how Blnk allocates tagged provider funds when spending from this balance.

  Supported values: `FIFO`, `LIFO`, `PROPORTIONAL`.
</ParamField>
<ParamField body="meta_data" type="object">
  Additional metadata for the request body.
</ParamField>

### Response
<ResponseField name="balance" type="integer" required>
  The net amount being stored in the balance.
</ResponseField>
<ResponseField name="inflight_balance" type="integer" required>
  The net amount waiting to be moved into or out of the balance.
</ResponseField>
<ResponseField name="credit_balance" type="integer" required>
  Total amount moved into the balance
</ResponseField>
<ResponseField name="inflight_credit_balance" type="integer" required>
  Total amount waiting to be moved into the balance.
</ResponseField>
<ResponseField name="debit_balance" type="integer" required>
  Total amount moved out of the balance.
</ResponseField>
<ResponseField name="inflight_debit_balance" type="integer" required>
  Total amount waiting to be moved out of the balance.
</ResponseField>
<ResponseField name="ledger_id" type="string" required>
  Always `general_ledger_id` for an internal balance.
</ResponseField>
<ResponseField name="indicator" type="string" required>
  The indicator you passed in the request.
</ResponseField>
<ResponseField name="identity_id" type="string">
  Unique id of the identity (if any) linked to this balance.
</ResponseField>
<ResponseField name="balance_id" type="string" required>
  Unique id of the created balance.
</ResponseField>
<ResponseField name="currency" type="string" required>
  The currency/asset class of the balance.
</ResponseField>
<ResponseField name="created_at" type="string" required>
  Indicates the date & time of creation.
</ResponseField>
<ResponseField name="meta_data" type="User Object">
  Additional metadata of the balance.
</ResponseField>
<ResponseField name="track_fund_lineage" type="boolean">
  Indicates whether fund lineage tracking is enabled for this balance.
</ResponseField>
<ResponseField name="allocation_strategy" type="string">
  The allocation strategy used for fund lineage spending when `track_fund_lineage` is enabled.
</ResponseField>

<RequestExample>
```bash wrap
curl -X POST "http://localhost:5001/balances" \
  -H "X-blnk-key: <api-key>" \
  -H "Content-Type: application/json" \
  -d '{
    "ledger_id": "general_ledger_id",
    "currency": "USD",
    "indicator": "@Revenue"
  }'
```
</RequestExample>
