Use `blnk.transactions.update_status` to commit or void an [inflight](/transactions/inflight) transaction or batch.

<Steps>
<Step title="Call the method">

<Tabs>
<Tab title="Commit">

```python blnk.transactions.update_status wrap
response = blnk.transactions.update_status(
  "txn_c4e70eb8-e4d6-4e04-a2e2-92a43b969e0c",
  {
    "status": "commit",
  },
)
```

</Tab>

<Tab title="Partial commit">

```python blnk.transactions.update_status wrap
response = blnk.transactions.update_status(
  "txn_c4e70eb8-e4d6-4e04-a2e2-92a43b969e0c",
  {
    "status": "commit",
    "amount": 500
  },
)
```

</Tab>

<Tab title="Void">

```python blnk.transactions.update_status wrap
response = blnk.transactions.update_status(
  "txn_c4e70eb8-e4d6-4e04-a2e2-92a43b969e0c",
  {
    "status": "void",
  },
)
```

</Tab>

<Tab title="Dry run">

Preview the commit or void without settling the hold. See [Dry-run transactions](/transactions/dry-run).

```python blnk.transactions.update_status wrap {5}
preview = blnk.transactions.update_status(
  "txn_c4e70eb8-e4d6-4e04-a2e2-92a43b969e0c",
  {
    "status": "commit",
    "dry_run": True,
  },
)
```

</Tab>
</Tabs>

| Field | Type | Description |
| :-- | :-- | :-- |
| `id` | `str` | Inflight transaction ID, or batch ID from create_bulk. |
| `status` | `str` | `commit` to apply funds, or `void` to cancel and roll back. |
| `amount` | `number` | Partial commit amount. See [Partial commits](/transactions/inflight#partial-commits). |
| `precise_amount` | `number` | Precision-applied partial commit amount. Takes precedence over amount. |

</Step>

<Step title="Confirm the outcome">

On a posted update, check `response.data["status"]` for `COMMIT` or `VOID`. Use `parent_transaction` to link the result back to the original inflight transaction.

A dry run has no `transaction_id`. Check `would_apply` instead.

</Step>

| :-- | :-- | :-- |
| `transaction_id` | `str` | ID of the new transaction created by the commit or void. |
| `parent_transaction` | `str` | Original inflight transaction this resolves. |
| `status` | `str` | `COMMIT` or `VOID`. |
| `precise_amount` | `number` | Amount applied (amount × precision). |
