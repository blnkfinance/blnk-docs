Use `blnk.transactions().refund` for this operation.

<Steps>
<Step title="Call the method">

<Tabs>
<Tab title="Skip queue">

```java wrap
String transactionId = "txn_c4e70eb8-e4d6-4e04-a2e2-92a43b969e0c";

ApiResponse<JsonNode> response = blnk.transactions().refund(
    transactionId,
    RefundTransactionRequest.create().skipQueue(true));
```

</Tab>

<Tab title="Description and metadata">

Set a narration and merge metadata onto the copy inherited from the original. See [Refunds](/transactions/refunds).

```java wrap
ApiResponse<JsonNode> response = blnk.transactions().refund(
    "txn_c4e70eb8-e4d6-4e04-a2e2-92a43b969e0c",
    RefundTransactionRequest.create()
        .description("Refund for ticket #4821")
        .metaData(Map.of(
            "type", "refund",
            "reason", "goodwill")));
```

</Tab>

<Tab title="Dry run">

Preview the refund without writing anything. See [Dry-run transactions](/transactions/dry-run).

```java wrap
ApiResponse<JsonNode> preview = blnk.transactions().refund(
    "txn_c4e70eb8-e4d6-4e04-a2e2-92a43b969e0c",
    RefundTransactionRequest.create().dryRun(true));
```

</Tab>
</Tabs>

| Field | Type | Description |
| :-- | :-- | :-- |
| `transactionId` | `String` | Transaction ID of the applied transaction to refund. |
| `skip_queue` | `boolean` | When `true`, process the refund synchronously instead of queuing. |
| `description` | `String` | Narration for the refund. When omitted or empty, the refund copies the original. |
| `meta_data` | `Map<String, Object>` | Merged onto metadata inherited from the original. |
| `dry_run` | `boolean` | Return a preview without creating a refund. |

</Step>

<Step title="Save the refund transaction ID">

On a posted refund, use `response.data().get("transaction_id").asText()` to track it.

A dry run has no `transaction_id`. Check `would_apply` instead.

</Step>

| Field | Type | Description |
| :-- | :-- | :-- |
| `transaction_id` | `String` | ID of the new refund transaction. |
| `parent_transaction` | `String` | Original transaction being refunded. |
| `source` | `String` | Original destination, now the source of the refund. |
| `destination` | `String` | Original source, now the destination of the refund. |
| `status` | `String` | Status of the refund transaction. |
