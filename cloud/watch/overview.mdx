Watch is Blnk's lightweight transaction monitoring engine. 

On Cloud, you can enable Watch on a managed instance so ledger transactions are evaluated against rules you define in a Git repository. When a rule matches, Watch returns a verdict such as `allow`, `review`, or `block`, and can surface flagged activity for your team to investigate.

## What Watch does in Cloud

With Watch enabled on an instance:

1. You connect a **Git repository** that contains your WatchScript (`.ws`) rule files.
2. Watch syncs those rules and evaluates transactions from your Core ledger.
3. Matching rules produce verdicts and can create **flagged alerts** for review.

Use Watch when you need transaction monitoring (limits, fraud checks, or compliance rules) without running the Watch service yourself.

## Watch vs Monitoring

Cloud also offers **Monitoring** on instance quick actions. These are different tools:

| | Watch | Monitoring |
| :-- | :-- | :-- |
| **Purpose** | Rule-based transaction monitoring and risk verdicts | Observability for traces, metrics, and logs |
| **Input** | Ledger transactions + WatchScript rules | Application telemetry |
| **Output** | Verdicts (`allow`, `review`, `block`) and flagged alerts | Dashboards for performance and debugging |

Use Watch to decide what to do with a transaction. Use Monitoring to understand how your instance is running.

## Where to find Watch

You can open Watch from two places in Cloud:

- **Instances → instance details → Quick Actions → Enable watch**: enable Watch for a specific instance
- **Settings → Watch**: overview of Watch and the Enable watch action
