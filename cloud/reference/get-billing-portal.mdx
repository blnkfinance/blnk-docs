Retrieve a Stripe customer portal URL. Open `portal_url` in a browser to update the payment method, invoices, or subscription. Cloud only returns the URL.

<RequestExample>
```bash cURL
curl -X GET 'https://api.cloud.blnkfinance.com/billing/portal' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

### Response

<ResponseExample>
```json 200
{
  "portal_url": "https://billing.stripe.com/p/session/YOUR_PORTAL_SESSION"
}
```
</ResponseExample>

<ResponseField name="portal_url" type="string" required>
Stripe customer portal URL. Open it in a browser. It is not a Cloud API callback.
</ResponseField>
