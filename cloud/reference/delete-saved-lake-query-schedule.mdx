---
title: "Delete query schedule"
api: "DELETE /data/lake/queries/{query_id}/schedule"
description: "Remove the schedule from a saved lake query."
---

import NeedHelp from "/cloud/snippets/need-help.mdx";
import Authorization from "/cloud/snippets/authorization.mdx";
import { RelatedTopics } from "/snippets/related-topics.jsx";

Remove the schedule from a saved lake query. The query itself stays saved. You can still run it with [Create new query](/cloud/reference/create-new-query). Cloud will not start any more scheduled [query runs](/cloud/reference/list-lake-query-runs). Past runs stay in history.

Only the query owner or an admin can delete the schedule.

---

<Authorization />

### Path

<RequestExample>
```bash cURL wrap
curl -X DELETE 'https://api.cloud.blnkfinance.com/data/lake/queries/lake_query_f482a1b3-6c2d-4e89-a17b-3d5e8f2a1c94/schedule' \
  -H 'Authorization: Bearer CLOUD_API_KEY'
```
</RequestExample>

<ParamField path="query_id" type="string" required>
Unique id of the saved query whose schedule you want to remove (`lake_query_...`). Get it from [Get saved query](/cloud/reference/get-saved-lake-query).
</ParamField>

### Response

A successful delete returns `204 No Content` with an empty body.

<ResponseExample>
```json 404 wrap
{
  "error": {
    "code": "NOT_FOUND",
    "message": "saved lake query not found"
  }
}
```

```json 403 wrap
{
  "error": {
    "code": "FORBIDDEN",
    "message": "lake query mutation is not permitted"
  }
}
```
</ResponseExample>
