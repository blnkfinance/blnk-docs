Retrieve invoices for your organization. `invoice_pdf` and `hosted_url` are Stripe links. Open them in a browser.

<RequestExample>
```bash cURL
curl -X GET 'https://api.cloud.blnkfinance.com/billing/invoices' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

### Response

<ResponseExample>
```json 200
{
  "invoices": [
    {
      "id": "in_1ABC123",
      "number": "INV-0001",
      "status": "paid",
      "amount_due": 0,
      "amount_paid": 5000,
      "currency": "usd",
      "description": "Sandbox Deployment",
      "invoice_pdf": "https://pay.stripe.com/invoice/...",
      "hosted_url": "https://invoice.stripe.com/i/...",
      "period_start": 1789118897,
      "period_end": 1789118918,
      "created": 1789118918,
      "subscription_id": "sub_1ABC123"
    }
  ]
}
```
</ResponseExample>

<ResponseField name="invoices" type="array" required>
Invoice objects for the organization.
<Expandable>
  <ResponseField name="id" type="string" required>
  Stripe invoice id.
  </ResponseField>
  <ResponseField name="number" type="string">
  Invoice number.
  </ResponseField>
  <ResponseField name="status" type="string" required>
  Invoice status, such as `paid` or `open`.
  </ResponseField>
  <ResponseField name="amount_due" type="integer">
  Amount due in the smallest currency unit.
  </ResponseField>
  <ResponseField name="amount_paid" type="integer">
  Amount paid in the smallest currency unit.
  </ResponseField>
  <ResponseField name="currency" type="string">
  ISO currency code, such as `usd`.
  </ResponseField>
  <ResponseField name="description" type="string">
  Line description, such as `Sandbox Deployment`.
  </ResponseField>
  <ResponseField name="invoice_pdf" type="string">
  URL of the PDF invoice.
  </ResponseField>
  <ResponseField name="hosted_url" type="string">
  URL of the hosted invoice page.
  </ResponseField>
  <ResponseField name="period_start" type="integer">
  Unix timestamp for the start of the invoice period.
  </ResponseField>
  <ResponseField name="period_end" type="integer">
  Unix timestamp for the end of the invoice period.
  </ResponseField>
  <ResponseField name="created" type="integer">
  Unix timestamp when the invoice was created.
  </ResponseField>
  <ResponseField name="subscription_id" type="string">
  Stripe subscription id this invoice belongs to. Can be empty.
  </ResponseField>
</Expandable>
</ResponseField>
