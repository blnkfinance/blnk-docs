Use this to list past invoices for the organization. `invoice_pdf` and `hosted_url` are hosted Stripe links. 

---

<Authorization />

<RequestExample>
```bash cURL wrap
curl -X GET "https://api.cloud.blnkfinance.com/billing/invoices" \
  -H "Authorization: Bearer CLOUD_API_KEY"
```
</RequestExample>

### Response

<ResponseExample>
```json 200 wrap expandable
{
  "invoices": [
    {
      "id": "in_1ABC123",
      "number": "INV-0001",
      "status": "paid",
      "amount_due": 0,
      "amount_paid": 5000,
      "currency": "usd",
      "description": "Sandbox Deployment",
      "invoice_pdf": "https://pay.stripe.com/invoice/...",
      "hosted_url": "https://invoice.stripe.com/i/...",
      "period_start": 1789118347,
      "period_end": 1791710347,
      "created": 1789118347,
      "subscription_id": "sub_1ABC123"
    }
  ]
}
```
</ResponseExample>

<ResponseField name="invoices" type="array">
Invoice objects for the organization.
<Expandable>
  <ResponseField name="id" type="string">
  Invoice id (`in_...`).
  </ResponseField>
  <ResponseField name="number" type="string">
  Invoice number.
  </ResponseField>
  <ResponseField name="status" type="string">
  Invoice status, such as `paid` or `open`.
  </ResponseField>
  <ResponseField name="amount_due" type="integer">
  Amount due in the smallest currency unit.
  </ResponseField>
  <ResponseField name="amount_paid" type="integer">
  Amount paid in the smallest currency unit.
  </ResponseField>
  <ResponseField name="currency" type="string">
  ISO currency code, such as `usd`.
  </ResponseField>
  <ResponseField name="description" type="string">
  Line description, such as `Sandbox Deployment`.
  </ResponseField>
  <ResponseField name="invoice_pdf" type="string">
  URL of the PDF invoice.
  </ResponseField>
  <ResponseField name="hosted_url" type="string">
  URL of the hosted invoice page.
  </ResponseField>
  <ResponseField name="period_start" type="integer">
  Unix timestamp (seconds) for the start of the invoice period.
  </ResponseField>
  <ResponseField name="period_end" type="integer">
  Unix timestamp (seconds) for the end of the invoice period.
  </ResponseField>
  <ResponseField name="created" type="integer">
  Unix timestamp (seconds) when the invoice was created.
  </ResponseField>
  <ResponseField name="subscription_id" type="string">
  Subscription id this invoice belongs to (`sub_...`). Can be empty.
  </ResponseField>
</Expandable>
</ResponseField>
