---
title: "Destroy deployment"
api: "DELETE /deployments/{id}/destroy"
description: "Destroy a managed Core instance through Blnk Cloud."
---

import NeedHelp from "/cloud/snippets/need-help.mdx";
import { RelatedTopics } from "/snippets/related-topics.jsx";

Destroy a managed instance. This action is irreversible.

---

### Path

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.cloud.blnkfinance.com/deployments/deploy_073f7ffe-9dfd-42ce-aa50-d1dca1788adc/destroy' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

<ParamField path="id" type="string" required>
Unique identifier of the deployment to destroy.
</ParamField>

---

### Response

<ResponseExample>
```json Success
{
  "message": "Deployment destruction initiated"
}
```
</ResponseExample>

<ResponseField name="message" type="string" required>
Confirmation that destruction has started.
</ResponseField>

A follow-up [Get deployment](/cloud/reference/get-deployment) shows `status: "DESTROYING"` and a `destroyed_at` timestamp, then `DESTROYED`.
