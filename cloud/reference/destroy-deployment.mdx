title: "Destroy deployment"
api: "DELETE /deployments/{deployment_id}/destroy"
description: "Destroy a managed Core instance through Blnk Cloud."

Use this endpoint to destroy a managed deployment. Cloud tears down the hosted Core and its infrastructure. See [Managed instances](/cloud/instances/deploy) to learn more.

The response means destroy has started, not that it is finished. Status moves to `DESTROYING`, then `DESTROYED`. Track progress with [Get deployment details](/cloud/reference/get-deployment) or [List deployments](/cloud/reference/list-deployments).

<Note>
This endpoint destroys managed instances only. For a connected (self-hosted) instance, stop your query agent or remove it from the [dashboard](/cloud/instances/create) to disconnect it from your Cloud workspace.
</Note>

<Warning>
**This action is irreversible**. Ledger data on that managed Core is deleted and cannot be recovered.
</Warning>

---

<Authorization />

### Path

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.cloud.blnkfinance.com/deployments/deploy_073f7ffe-9dfd-42ce-aa50-d1dca1788adc/destroy' \
  -H 'X-blnk-key: CLOUD_API_KEY'
```
</RequestExample>

<ParamField path="deployment_id" type="string" required>
Unique id of the deployment to destroy (`deploy_...`). Do not pass `instance_id` here.
</ParamField>

### Response

<ResponseExample>
```json 200
{
  "message": "Deployment destruction initiated"
}
```
</ResponseExample>

<ResponseField name="message" type="string">
Confirmation that destroy has started. A follow-up [Get deployment details](/cloud/reference/get-deployment) shows `status: "DESTROYING"` and a `destroyed_at` timestamp, then `DESTROYED`.
</ResponseField>
