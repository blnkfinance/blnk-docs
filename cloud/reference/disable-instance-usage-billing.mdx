---
title: "Disable instance usage billing"
api: "DELETE /billing/instances/{id}/usage-billing"
description: "Disable usage-based billing on a Core instance."
---

import NeedHelp from "/cloud/snippets/need-help.mdx";
import { RelatedTopics } from "/snippets/related-topics.jsx";

<Note>
Disable usage-based billing on one instance. `{id}` is the Cloud `instance_id` (`instance_...`), not a `deployment_id`.
</Note>

### Path

<RequestExample>
```bash cURL
curl -X DELETE 'https://api.cloud.blnkfinance.com/billing/instances/instance_073f7ffe-9dfd-42ce-aa50-d1dca1788adc/usage-billing' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

<ParamField path="id" type="string" required>
Cloud instance id.
</ParamField>

### Response

<ResponseExample>
```json 200
{
  "usage_billing_enabled": false
}
```

```json 404
{
  "error": "Instance not found"
}
```
</ResponseExample>

<ResponseField name="usage_billing_enabled" type="boolean" required>
`false` after usage-based billing is turned off. `usage_billing_enabled_at` is omitted.
</ResponseField>
