title: "Enable usage billing"

Enable usage-based billing for the organization. All instances under that organization are charged once they exceed their included usage. If it is already enabled, Cloud returns the same result. You cannot disable it from this API.

<Warning>
To learn more about usage-based billing, see [Usage-based billing](/cloud/organization/billing#usage-based-billing). To see overage per instance, use [Get record counts](/cloud/reference/get-record-counts).
</Warning>

---

<Authorization />

<RequestExample>
```bash cURL wrap
curl -X POST "https://api.cloud.blnkfinance.com/billing/usage-billing" \
  -H "Authorization: Bearer CLOUD_API_KEY" \
  -H "Content-Type: application/json" \
  -d '{}'
```
</RequestExample>

### Response

<ResponseExample>
```json 200 wrap
{
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-09T07:20:08.028229Z"
}
```
</ResponseExample>

<ResponseField name="usage_billing_enabled" type="boolean">
Whether usage-based billing is on for the organization.
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled for the organization. ISO 8601.
</ResponseField>
