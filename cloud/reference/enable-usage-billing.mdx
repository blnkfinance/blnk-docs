Enable usage-based billing for the organization. If it is already on, the same object is returned.

<RequestExample>
```bash cURL
curl -X POST 'https://api.cloud.blnkfinance.com/billing/usage-billing' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{}'
```
</RequestExample>

### Response

<ResponseExample>
```json 200
{
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-09T07:20:08.028229Z"
}
```
</ResponseExample>

<ResponseField name="usage_billing_enabled" type="boolean" required>
Whether usage-based billing is on.
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled.
</ResponseField>
