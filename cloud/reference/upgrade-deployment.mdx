Upgrade a managed instance the same way the dashboard upgrade flow does. Production payment-method rules match the dashboard.

### Path

<RequestExample>
```bash cURL
curl -X POST 'https://api.cloud.blnkfinance.com/deployments/deploy_073f7ffe-9dfd-42ce-aa50-d1dca1788adc/upgrade' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{}'
```
</RequestExample>

<ParamField path="id" type="string" required>
Unique identifier of the deployment to upgrade.
</ParamField>
