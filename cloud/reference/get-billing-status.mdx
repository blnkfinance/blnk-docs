---
title: "Get billing status"
api: "GET /billing/org"
description: "Return the organization plan, renewal date, and whether usage-based billing is enabled."
---

import NeedHelp from "/cloud/snippets/need-help.mdx";
import Authorization from "/cloud/snippets/authorization.mdx";

Use this to get your organization plan, subscription status, and renewal time.

For payment method, upcoming charge, and the subscription list, use [Get billing overview](/cloud/reference/get-billing-overview). For allowance and whether one instance is blocked, use [Get record counts](/cloud/reference/get-record-counts).

---

<Authorization />

<RequestExample>
```bash cURL wrap
curl -X GET "https://api.cloud.blnkfinance.com/billing/org" \
  -H "X-blnk-key: CLOUD_API_KEY"
```
</RequestExample>

### Response

<ResponseExample>
```json 200 wrap
{
  "billing_id": "bil_073f7ffe-9dfd-42ce-aa50-d1dca1788adc",
  "billing_email": "billing@example.com",
  "plan": "PRODUCTION_MONTHLY",
  "created_at": "2026-03-02T12:50:33.852747Z",
  "status": "ACTIVE",
  "last_update": "2026-09-09T07:20:10.260935Z",
  "next_renewal": "2026-10-07T12:50:27Z",
  "has_billing_history": true,
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-09T07:20:08.028229Z"
}
```
</ResponseExample>

<ResponseField name="billing_id" type="string">
Unique identifier for the organization billing record (`bil_...`).
</ResponseField>

<ResponseField name="billing_email" type="string">
Email on the billing account.
</ResponseField>

<ResponseField name="plan" type="string">
Organization plan code, such as `PRODUCTION_MONTHLY`.
</ResponseField>

<ResponseField name="created_at" type="timestamp">
When the organization billing record was created. ISO 8601.
</ResponseField>

<ResponseField name="status" type="string">
Organization subscription status, such as `ACTIVE`.
</ResponseField>

<ResponseField name="last_update" type="timestamp">
When the billing record was last updated. ISO 8601.
</ResponseField>

<ResponseField name="next_renewal" type="timestamp">
When the current plan renews. ISO 8601. Overview uses a Unix `next_billing_date` for the next charge.
</ResponseField>

<ResponseField name="has_billing_history" type="boolean">
Whether the organization has past invoices or charges.
</ResponseField>

<ResponseField name="usage_billing_enabled" type="boolean">
Whether usage-based billing is on for the organization. See [Usage-based billing](/cloud/organization/billing#usage-based-billing).
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled for the organization. ISO 8601.
</ResponseField>
