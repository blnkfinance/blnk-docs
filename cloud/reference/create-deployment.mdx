---

Create a managed Core instance programmatically.

### Body

<RequestExample>
```bash cURL
curl -X POST 'https://api.cloud.blnkfinance.com/deployments' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "name": "my-sandbox",
    "tier": "B1.Micro",
    "type": "sandbox"
  }'
```
</RequestExample>

<ParamField body="name" type="string" required>
Display name for the instance.
</ParamField>

<ParamField body="tier" type="string" required>
Capacity tier. Sandbox uses `B1.Micro`. Production typically uses `B1.Standard`.
</ParamField>

<ParamField body="type" type="string">
Deployment type: `sandbox` or `production`.
</ParamField>

<ParamField body="region" type="string">
Optional datacenter. If omitted, Cloud assigns one.
</ParamField>

### Response

<ResponseExample>
```json 201
{
  "deployment_id": "deploy_073f7ffe-9dfd-42ce-aa50-d1dca1788adc",
  "name": "my-sandbox",
  "ingress_mode": "shared",
  "dedicated": false,
  "tier": "B1.Micro",
  "type": "sandbox",
  "region": "nyc3",
  "status": "PENDING",
  "has_db_access": false,
  "watch_enabled": false,
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-09T07:20:08.028229Z",
  "record_creates_blocked": false,
  "created_at": "2026-09-11T09:28:16.864765Z",
  "updated_at": "2026-09-11T09:28:16.864765Z"
}
```

```json 400
{
  "error": "Key: 'CreateDeploymentRequest.Name' Error:Field validation for 'Name' failed on the 'required' tag"
}
```
</ResponseExample>

<ResponseField name="deployment_id" type="string" required>
Unique identifier for the deployment.
</ResponseField>

<ResponseField name="name" type="string" required>
Instance name.
</ResponseField>

<ResponseField name="type" type="string" required>
`sandbox` or `production`.
</ResponseField>

<ResponseField name="tier" type="string" required>
Capacity tier, such as `B1.Micro` or `B1.Standard`.
</ResponseField>

<ResponseField name="status" type="string" required>
`PENDING` until the instance is ready, then `ACTIVE`. Sandbox typically takes 7 - 10 minutes. Production can take 10 - 30 minutes.
</ResponseField>

<ResponseField name="region" type="string">
Datacenter code for the instance.
</ResponseField>

<ResponseField name="dedicated" type="boolean">
`true` for dedicated (Production) infrastructure.
</ResponseField>

<ResponseField name="ingress_mode" type="string">
How Cloud routes traffic to the instance. Live values include `shared` and `legacy`.
</ResponseField>

<ResponseField name="has_db_access" type="boolean">
Whether database access is enabled on this deployment.
</ResponseField>

<ResponseField name="watch_enabled" type="boolean">
Whether Watch is enabled.
</ResponseField>

<ResponseField name="usage_billing_enabled" type="boolean">
Whether usage-based billing is on for the workspace.
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled.
</ResponseField>

<ResponseField name="record_creates_blocked" type="boolean">
`true` when the instance cannot create new records.
</ResponseField>

<ResponseField name="created_at" type="timestamp" required>
When the deployment was created.
</ResponseField>

<ResponseField name="updated_at" type="timestamp" required>
When the deployment was last updated.
</ResponseField>

Poll [Get deployment](/cloud/reference/get-deployment) until `status` is `ACTIVE`. Then `url` and `domain` are present.
