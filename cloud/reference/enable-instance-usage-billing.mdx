title: "Enable instance usage billing"
api: "POST /billing/instances/{id}/usage-billing"
description: "Enable usage-based billing on a Core instance."
---

import NeedHelp from "/cloud/snippets/need-help.mdx";
import { RelatedTopics } from "/snippets/related-topics.jsx";

<Note>
Enable usage-based billing on one instance. `{id}` is the Cloud `instance_id` (`instance_...`), not a `deployment_id`.
</Note>

### Path

<RequestExample>
```bash cURL
curl -X POST 'https://api.cloud.blnkfinance.com/billing/instances/instance_073f7ffe-9dfd-42ce-aa50-d1dca1788adc/usage-billing' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{}'
```
</RequestExample>

<ParamField path="id" type="string" required>
Cloud instance id. A `deploy_...` id returns `404`.
</ParamField>

### Response

<ResponseExample>
```json 200
{
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-11T10:37:13.631475Z"
}
```

```json 404
{
  "error": "Instance not found"
}
```
</ResponseExample>

<ResponseField name="usage_billing_enabled" type="boolean" required>
Whether usage-based billing is on for the instance.
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled.
</ResponseField>
