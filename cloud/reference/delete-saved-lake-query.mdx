---
title: "Delete saved query"
api: "DELETE /data/lake/queries/{query_id}"
description: "Delete a saved lake query and its schedule."
---

import NeedHelp from "/cloud/snippets/need-help.mdx";
import Authorization from "/cloud/snippets/authorization.mdx";
import { RelatedTopics } from "/snippets/related-topics.jsx";

Delete a saved lake query. Cloud also deletes its schedule if one exists. You can no longer run it with `saved_query_id`. Only the query owner or an admin can delete it.

Past [query runs](/cloud/reference/list-lake-query-runs) stay in history. Each run keeps the SQL snapshot from when it executed.

---

<Authorization />

### Path

<RequestExample>
```bash cURL wrap
curl -X DELETE 'https://api.cloud.blnkfinance.com/data/lake/queries/lake_query_f482a1b3-6c2d-4e89-a17b-3d5e8f2a1c94' \
  -H 'Authorization: Bearer CLOUD_API_KEY'
```
</RequestExample>

<ParamField path="query_id" type="string" required>
Unique id of the saved query to delete (`lake_query_...`). Get it from [Get saved query](/cloud/reference/get-saved-lake-query).
</ParamField>

### Response

A successful delete returns `204 No Content` with an empty body.

<ResponseExample>
```json 404 wrap
{
  "error": {
    "code": "NOT_FOUND",
    "message": "saved lake query not found"
  }
}
```

```json 403 wrap
{
  "error": {
    "code": "FORBIDDEN",
    "message": "lake query mutation is not permitted"
  }
}
```
</ResponseExample>
