title: "Get usage billing"
api: "GET /billing/usage-billing"

Check whether usage-based billing is enabled for the organization. When it is, all instances under that organization are charged once they exceed their included usage.

To see usage for one instance, use [Get record counts](/cloud/reference/get-record-counts). To enable it, use [Enable usage billing](/cloud/reference/enable-usage-billing).

---

<Authorization />

<RequestExample>
```bash cURL wrap
curl -X GET "https://api.cloud.blnkfinance.com/billing/usage-billing" \
  -H "Authorization: Bearer CLOUD_API_KEY"
```
</RequestExample>

### Response

<ResponseExample>
```json 200 wrap
{
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-09T07:20:08.028229Z"
}
```
</ResponseExample>

<ResponseField name="usage_billing_enabled" type="boolean">
Whether usage-based billing is on for the organization. See [Usage-based billing](/cloud/organization/billing#usage-based-billing).
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled for the organization. ISO 8601.
</ResponseField>
