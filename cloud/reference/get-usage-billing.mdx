Retrieve whether usage-based billing is enabled for the organization.

<RequestExample>
```bash cURL
curl -X GET 'https://api.cloud.blnkfinance.com/billing/usage-billing' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

### Response

<ResponseExample>
```json 200
{
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-09T07:20:08.028229Z"
}
```
</ResponseExample>

<ResponseField name="usage_billing_enabled" type="boolean" required>
Whether usage-based billing is on.
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled.
</ResponseField>
