---
title: "Update deployment config"
api: "PUT /deployments/{id}/config"
description: "Update configuration for a managed Core instance."
---

import NeedHelp from "/cloud/snippets/need-help.mdx";
import { RelatedTopics } from "/snippets/related-topics.jsx";

Update configuration for a deployment. Send a JSON object of keys from [Get deployment config](/cloud/reference/get-deployment-config). Cloud applies the config and restarts the instance.

---

### Path

<RequestExample>
```bash cURL
curl -X PUT 'https://api.cloud.blnkfinance.com/deployments/deploy_073f7ffe-9dfd-42ce-aa50-d1dca1788adc/config' \
  -H 'Authorization: Bearer YOUR_API_KEY' \
  -H 'Content-Type: application/json' \
  -d '{
    "BLNK_WEBHOOK_URL": "https://example.com/webhooks/blnk"
  }'
```
</RequestExample>

<ParamField path="id" type="string" required>
Unique identifier of the deployment.
</ParamField>

### Body

<ParamField body="BLNK_WEBHOOK_URL" type="string">
Example override. Any key from `allowed_keys` on Get deployment config is valid.
</ParamField>

---

### Response

<ResponseExample>
```json 202
{
  "message": "Configuration applied; your instance is restarting with the new settings"
}
```
</ResponseExample>

<ResponseField name="message" type="string" required>
Confirmation that the config was applied and the instance is restarting.
</ResponseField>
