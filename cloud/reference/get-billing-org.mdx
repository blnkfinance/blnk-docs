Retrieve the billing record for your organization.

<RequestExample>
```bash cURL
curl -X GET 'https://api.cloud.blnkfinance.com/billing/org' \
  -H 'Authorization: Bearer YOUR_API_KEY'
```
</RequestExample>

### Response

<ResponseExample>
```json 200
{
  "billing_id": "bil_073f7ffe-9dfd-42ce-aa50-d1dca1788adc",
  "billing_email": "billing@example.com",
  "work_os_org_id": "org_01ABC123DEF456",
  "plan": "PRODUCTION_MONTHLY",
  "created_at": "2026-03-02T12:50:33.852747Z",
  "status": "ACTIVE",
  "last_update": "2026-09-09T07:20:10.260935Z",
  "next_renewal": "2026-10-07T12:50:27Z",
  "has_billing_history": true,
  "usage_billing_enabled": true,
  "usage_billing_enabled_at": "2026-09-09T07:20:08.028229Z"
}
```
</ResponseExample>

<ResponseField name="billing_id" type="string" required>
Unique identifier for the organization billing record.
</ResponseField>

<ResponseField name="billing_email" type="string" required>
Email on the billing account.
</ResponseField>

<ResponseField name="work_os_org_id" type="string" required>
Organization id in WorkOS.
</ResponseField>

<ResponseField name="plan" type="string" required>
Current plan, such as `PRODUCTION_MONTHLY`.
</ResponseField>

<ResponseField name="created_at" type="timestamp" required>
When billing was created.
</ResponseField>

<ResponseField name="status" type="string" required>
Billing status, such as `ACTIVE`.
</ResponseField>

<ResponseField name="last_update" type="timestamp">
When billing was last updated.
</ResponseField>

<ResponseField name="next_renewal" type="timestamp">
When the current plan renews.
</ResponseField>

<ResponseField name="has_billing_history" type="boolean">
Whether the organization has past invoices or charges.
</ResponseField>

<ResponseField name="usage_billing_enabled" type="boolean">
Whether usage-based billing is on for the organization.
</ResponseField>

<ResponseField name="usage_billing_enabled_at" type="timestamp">
When usage-based billing was enabled.
</ResponseField>
