The Blnk MCP server exposes your Core instance through the [Model Context Protocol (MCP)](https://modelcontextprotocol.io/). 

AI tools such as Cursor, Claude Desktop, and ChatGPT connect to this endpoint, authenticate with Blnk Cloud credentials, and call tools to read or write ledger data.

**All MCP traffic is routed through Blnk Cloud**. AI clients never connect directly to your Core instance. Cloud validates credentials, enforces scopes, and forwards authorized operations to the target instance.

<RequestExample>
```json MCP configuration wrap
{
  "mcpServers": {
    "blnk": {
      "url": "https://api.cloud.blnkfinance.com/mcp/YOUR_INSTANCE_ID",
      "headers": {
        "X-blnk-key": "CLOUD_API_KEY"
      }
    }
  }
}
```
</RequestExample>

## Set up your client

<Steps>
<Step title="Create authentication credentials">
Choose either an API key or OAuth credentials. Both need `mcp:read` and `mcp:write`.

<Tabs>
<Tab title="API Key" icon="key">
Create an API key with MCP scopes in [Settings > API Keys](/cloud/reference/api-keys#create-an-api-key).
</Tab>
<Tab title="OAuth Credentials" icon="lock">
Create an OAuth client with MCP scopes in [Settings > API Keys](/cloud/reference/oauth#create-an-oauth-client). Select `OAuth` as the type when creating.
</Tab>
</Tabs>
</Step>

<Step title="Get your MCP endpoint">
Go to `Settings > MCP` and copy the configuration for your app.

<Tabs>
<Tab title="API Key" icon="key">
```json wrap
{
  "mcpServers": {
    "blnk": {
      "url": "https://api.cloud.blnkfinance.com/mcp/YOUR_INSTANCE_ID",
      "headers": {
        "X-blnk-key": "CLOUD_API_KEY"
      }
    }
  }
}
```
</Tab>
<Tab title="OAuth Credentials" icon="lock">
```
https://api.cloud.blnkfinance.com/mcp/YOUR_INSTANCE_ID
```

<Info>
For OAuth, you only need the MCP endpoint URL. Use your OAuth Client ID and Client Secret for authentication.
</Info>
</Tab>
</Tabs>
</Step>

<Step title="Configure your MCP client">
<Tabs>
<Tab title="Cursor" icon="code">
1. Open Cursor Settings.
2. Go to `Features > MCP Servers`.
3. Click `Add Server`.
4. Paste the configuration from the previous step (full JSON for API keys, or the endpoint URL for OAuth).
</Tab>
<Tab title="Claude Desktop" icon="bot">
Add the configuration from the previous step to `claude_desktop_config.json`:

<CodeGroup>
```bash MacOS wrap
~/Library/Application Support/Claude/claude_desktop_config.json
```

```bash Windows wrap
%APPDATA%\Claude\claude_desktop_config.json
```
</CodeGroup>
</Tab>
<Tab title="ChatGPT" icon="bot">
1. Go to `Settings > Apps`.

<img src="/cloud/img/organization/chatgpt-setup.png" alt="ChatGPT MCP app configuration form showing fields for Name, MCP Server URL, and OAuth authentication settings" />

2. Open `Advanced settings` and enable `Developer mode`.
3. Click `Create app`.
4. Fill in the app details:
   - **Name:** Use a clear name like Blnk MCP.
   - **MCP Server URL:** Paste the MCP endpoint URL from the previous step.
   - **Authentication type:** Select OAuth, then enter your Client ID and Client Secret.
5. Click `Create`.
6. Sign in with Blnk Cloud when prompted.
7. After login, ChatGPT returns with the MCP app configured.
</Tab>
</Tabs>
</Step>

<Step title="Start chatting with your ledger">
You can now query, explore, and update Blnk data from your assistant.
</Step>
</Steps>

## What you can ask

1. **Monitor activity**
   - "Show me all transactions from the last 24 hours"
   - "What changed since yesterday?"

2. **Check balances**
   - "What is the current balance for wallet bln_wallet_456?"
   - "Show me all negative or low balances"

3. **Investigate issues**
   - "Find failed or voided transactions"
   - "Get the transaction with reference order_456"

4. **Review large movements**
   - "Show all USD transactions over $5,000"
   - "List unusually large transactions today"

5. **Answer operational questions**
   - "How much money moved today?"
   - "What is the total balance across all customer wallets?"

6. **Query the lake (archived data)**
   - "Show the lake schema, then count APPLIED transactions last month"
   - "Save a rolling 30-day currency breakdown query and schedule it daily"

7. **Operate Core workflows**
   - "Create a balance monitor that alerts when this wallet goes below 1000"
   - "Bulk commit these inflight transactions"
   - "Start a reconciliation with this matching rule"

## Supported tools

Blnk MCP registers 74 tools: 4 ledgers, 14 balances, 13 transactions, 10 identities, 3 search, 4 filters, 7 reconciliation, 5 hooks, 1 metadata, 2 system, and 11 lake.

<Tabs>
<Tab title="Ledgers" icon="book-open">
- `create_ledger` - Create a new ledger for organizing balances
- `get_ledger` - Retrieve ledger details by ID
- `list_ledgers` - List all ledgers
- `update_ledger` - Update the name of an existing ledger
</Tab>
<Tab title="Balances" icon="wallet">
- `create_balance` - Create a balance within a ledger
- `get_balance` - Retrieve balance details by ID
- `list_balances` - List all balances
- `get_balance_by_indicator` - Retrieve a balance by its indicator and currency
- `take_balance_snapshots` - Start daily balance snapshots
- `get_historical_balance` - Get a balance as of a timestamp
- `get_balance_lineage` - Get fund lineage for a balance
- `update_balance_identity` - Link or change the identity on a balance
- `create_balance_monitor` - Create a balance monitor that fires when a condition is met
- `get_balance_monitor` - Retrieve a balance monitor by ID
- `list_balance_monitors` - List all balance monitors on the instance
- `list_balance_monitors_by_balance` - List balance monitors for a specific balance
- `update_balance_monitor` - Update an existing balance monitor
- `delete_balance_monitor` - Delete a balance monitor by ID
</Tab>
<Tab title="Transactions" icon="arrow-left-right">
- `record_transaction` - Record a transaction between balances
- `get_transaction` - Get a transaction by ID
- `get_transaction_by_reference` - Get a transaction by its unique reference
- `list_transactions` - List transactions on the instance
- `commit_inflight` - Commit an inflight transaction to finalize it
- `void_inflight` - Void an inflight transaction to cancel it
- `bulk_commit_inflight` - Commit multiple independently created inflight transactions
- `bulk_void_inflight` - Void multiple independently created inflight transactions
- `recover_queued_transactions` - Recover stuck queued transactions
- `refund_transaction` - Create a refund for a transaction
- `schedule_transaction` - Schedule a transaction for future execution
- `bulk_transactions` - Create multiple transactions in one request
- `get_transaction_lineage` - Get fund lineage for a transaction
</Tab>
<Tab title="Identities" icon="users">
- `create_identity` - Create a new identity (individual or organization)
- `get_identity` - Retrieve identity details by ID
- `list_identities` - List all identities
- `update_identity` - Update an existing identity
- `delete_identity` - Delete an identity
- `tokenize_field` - Tokenize one PII field on an identity
- `tokenize_identity` - Tokenize multiple PII fields on an identity
- `detokenize_field` - Detokenize one PII field on an identity
- `detokenize_identity` - Detokenize multiple PII fields on an identity
- `get_tokenized_fields` - List which fields are tokenized on an identity
</Tab>
<Tab title="Search" icon="search">
- `search` - Search across transactions, ledgers, balances, or identities
- `start_reindex` - Start a Typesense reindex
- `get_reindex` - Get Typesense reindex progress
</Tab>
<Tab title="Filters" icon="database">
- `query_transactions` - Query transactions with advanced filters
- `query_balances` - Query balances with advanced filters
- `query_ledgers` - Query ledgers with advanced filters
- `query_identities` - Query identities with advanced filters
</Tab>
<Tab title="Reconciliation" icon="scale-balanced">
- `upload_reconciliation_data` - Upload external reconciliation data (CSV or JSON)
- `create_matching_rule` - Create a reconciliation matching rule
- `update_matching_rule` - Update a reconciliation matching rule
- `delete_matching_rule` - Delete a reconciliation matching rule
- `start_reconciliation` - Start a batch reconciliation run
- `start_instant_reconciliation` - Start instant reconciliation with inline external transactions
- `get_reconciliation` - Get reconciliation run status and results
</Tab>
<Tab title="Hooks" icon="webhook">
- `create_hook` - Register a transaction hook
- `update_hook` - Update a hook
- `get_hook` - Get a hook by ID
- `list_hooks` - List hooks
- `delete_hook` - Delete a hook
</Tab>
<Tab title="Metadata" icon="tags">
- `update_metadata` - Add or update metadata on a ledger, balance, transaction, or identity
</Tab>
<Tab title="System" icon="server">
- `get_health` - Check Core server health
- `get_metrics` - Read Core Prometheus metrics
</Tab>
<Tab title="Lake" icon="layers">
- `lake_schema` - Get lake resources and columns for writing SQL
- `lake_query` - Run SQL against archived lake data (or a saved query)
- `list_lake_queries` - List saved lake queries for this instance
- `get_lake_query` - Get a saved lake query by ID
- `create_lake_query` - Create a saved lake query (does not execute it)
- `update_lake_query` - Update a saved lake query you own (or as admin)
- `delete_lake_query` - Delete a saved lake query you own (or as admin)
- `list_lake_query_runs` - List recent lake query runs
- `get_lake_query_run` - Get a lake query run by ID
- `put_lake_query_schedule` - Create or update a cron schedule for a saved query you own (or as admin)
- `delete_lake_query_schedule` - Delete the schedule for a saved lake query you own (or as admin)
</Tab>
</Tabs>

## Response

Blnk MCP follows the [Model Context Protocol specification](https://modelcontextprotocol.io/specification/2025-03-26). Request and response formats, session lifecycle, transport, and error handling are defined by the MCP standard.

Most MCP clients handle the protocol automatically. If you are building a custom client, refer to the MCP specification for message structure, initialization, and tool invocation.
